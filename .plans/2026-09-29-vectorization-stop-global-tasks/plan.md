# 执行计划：批量向量化故障止损与全局状态提示

## 目标

系统性 embedding 故障能停止后续批次并安全收束；CLI 与 Web 批量任务可在同机同数据目录下被 Web 自动发现；页面切换时仍能看见当前 scope 的维度告警和任务状态。

## 完成判据

- [x] provider 的永久故障和有限重试耗尽能经调度器、引擎、向量客户端传到批量调用方，停止尚未开始的后续 embedding 批次；单条坏数据仍可继续。
- [x] 重建在切换前失败可保留旧向量集合；导入提前停止会执行现有回滚/补偿并准确记录已提交、失败和未处理数量。
- [x] `--no-vector` 全文模式在向量服务不可用时不调用 embedding，导入仍可完成。
- [x] 同数据目录下 CLI 直连、daemon 和 Web 导入任务都能出现在任务列表；心跳过期不显示成功；登记/查询故障有明确反馈。
- [x] 任务列表与详情遵守 scope 授权；旧 import/restore 状态接口继续可用且不会把系统性失败映射为成功。
- [x] 全局维度状态接口在长任务期间不被同 scope 操作队列阻塞；切换页面/scope 后横幅显示对应诊断，未知/过期时明确显示无法确认。
- [x] Web 新增后台任务页和明显的运行态摘要；动画遵守 `prefers-reduced-motion`，任务结束后停止。
- [x] 相关自动化检查及真实 CLI/Web 故障演练有命令和结果记录；所有 P0 自评项通过。
