## 1. 页面与结构

| # | 界面 | 目的 | 首要信息 | 次要信息 |
|---|---|---|---|---|
| P1 | **对话面板（既有）** | 继续作为主入口 | 消息流 | 会话切换、来源、**工具调用** |

## 2. 布局

### 2.1 P1 面板头部（唯一的结构改动）

```
┌──────────────────────────────────────────────┐
│ AI 对话   [◰ 会话名  6 ▾]        [⚙]        │  ← 默认态
└──────────────────────────────────────────────┘
       ↑ 既有                        ↑ 新增（唯一结构改动）
```

⚙ 放在最右、与会话 chip 同排，**不新增第二条折叠条**（既有走查结论：面板内再加折叠就不像聊天应用）。

### 2.2 P2 配置抽屉（**两级结构：列表 → 详情(预览/编辑)**）

> 2026-09-30 修正（用户反馈）：提示词与 skill 的**内容不直接摊开**——列表层只显示条目卡片
> （名称 + 一行摘要 + 状态），点开先看**预览**，再点「编辑」才进入编辑态；**skill 是列表**（可多条）。

```
列表层（默认）
┌────────────────────────────┐
│ 对话配置              [✕]  │
│ 作用域  [全局 ▾]           │
│         · 下一次提问生效    │
│ ── 提示词 ───────────────  │
│ ┌────────────────────────┐ │
│ │ ▤ 基础提示词           │ │
│ │   你是 kisearch 的…    │ │  ← 一行摘要（截断）
│ │   218 字 · 已修改   ▸  │ │
│ └────────────────────────┘ │
│ ── Skill ────────────────  │
│ ┌────────────────────────┐ │
│ │ ⚙ 知识库检索            │ │
│ │   先 ki_search 找片段…  │ │
│ │   486 字 · 默认     ▸  │ │
│ └────────────────────────┘ │
│ + 新增 skill               │  ← 虚线（数据模型待定，见待确认 10）
│ ── 工具与权限 ────────────  │
│ 只读 …（开关）              │
│ 写入·危险 …（开关+确认）     │
└────────────────────────────┘

详情层（点条目后）
┌ ‹ 返回   基础提示词 ────── ✕ ┐
│ [ 预览 | 编辑 ]   ← 分段切换  │
│ ──────────────────────────  │
│ 预览：只读正文 + 元信息        │
│   218 字 · 上次修改 09-30     │
│ 编辑：多行编辑区 + 字数校验     │
├───────────────────────────  │
│ [恢复默认]    [取消] [保存]   │
└─────────────────────────────┘
```

**两级保存口径**：详情层**自己保存**该条目（保存后回列表、卡片状态更新）；列表层底部保存栏负责**作用域 + 工具开关**。两条路径都用 toast 反馈，避免"改了不知道存没存"。

## 3. 组件与状态

| 组件 | 状态 | 视觉 |
|---|---|---|
| 面板头 ⚙ 按钮 | 默认 / 悬停 / 聚焦 / 按下 | 32×32 图标钮；悬停 `--ki-color-hover`；聚焦 2px `--ki-color-primary` 环；按下 `scale(.96)` |
| 抽屉 | 关闭 / 打开 / 保存中 / 保存成功 / 保存失败 | 右侧滑入 240ms；遮罩 `rgba(0,0,0,.24)`；保存中按钮 spinner + 禁用；成功为按钮内 1.2s「已保存」+ 顶部细条；失败为红字 inline（**不用 alert**） |
| 文本编辑区 | 默认 / 聚焦 / 超长 / 空 / 禁用 | 聚焦边框转 `--ki-color-primary`；超长红边 + 计数变红；空值给「不能为空」inline 提示 |
| 工具开关 | 开 / 关 / 禁用 / 危险待确认 | 36×20 胶囊；开=`--ki-color-primary`；危险组开关关闭态描边 `--ki-color-warning`；点击开 **必弹二次确认** |
| 危险确认弹层 | 默认 / 确认中 | 说明「开启后 AI 可删除当前 scope 的知识库关系，不可撤销」+ 取消/确认（确认按钮用 danger） |
| 工具调用项 | 收起 / 展开 / 运行中 / 失败 | 沿用基准 demo 的 `.tl__node`；运行中左侧脉冲点；失败左侧三角 + `--ki-color-warning` |
| 展开面板（**入参 / 响应 / 元信息**） | 默认 / 长内容 / 失败 | **卡片**：`bg-secondary` 底 + 边框 + 8px 圆角；分节（入参 / 响应 / 说明）；**入参用等宽 JSON 块**（`surface` 底 + 6px 圆角 + 键/串/数字分色）；**响应用命中行**（序号 / 文档 / 行号 / 分数，`tabular-nums`，行内 hover，点击回原文）；正文 13px、值用 `text`（非 muted）；失败用警告色边框与文案 |
| 展开面板的对比度 | — | 12–13px、值色 `--ki-color-text`、标签 `--ki-color-text-muted`、补说明 `--ki-color-text-subtle`；**禁止整块 11px 灰字** |
| 恢复默认 | 默认 / 悬停 / 确认 | 文字钮；点击后**先提示**「将丢弃当前修改」，确认后回填默认值 |
| 列表卡片（提示词 / Skill 条目） | 默认 / 悬停 / **已修改** / **默认值** | 名称 + 一行摘要（截断）+ 元信息（字数 · 状态）；悬停底色；已修改加「已修改」徽标；未改过的显示「默认」 |
| 详情分段（预览 \| 编辑） | 预览 / 编辑 | 分段控件（复用 `.seg` 范式）；**默认落在预览**；编辑才出现编辑区与字数校验 |
| 详情返回（有未保存修改） | 直接返回 / 确认丢弃 | 无修改直接返回；有修改弹「将丢弃未保存的修改」确认 |
| 新增 / 删除 Skill | 新增（虚线行，进编辑态）/ 删除（确认） | 新增给空模板；删除仅对**非内置**条目开放，内置条目只能"恢复默认" |

## 4. 视觉 token

**100% 复用 `ki.css`**（`--ki-*`），本方案不新增任何全局 token。仅新增 3 个面板级变量（沿用基准 demo 的 `--ki-chat-*` 命名）：

| token | 值 | 用途 |
|---|---|---|
| `--ki-chat-config-w` | `420px` | 配置抽屉宽度 |
| `--ki-chat-tool-max-h` | `240px` | 工具展开区滚动上限 |
| `--ki-chat-tool-indent` | `14px` | 工具展开区左缩进（与时间线节点对齐） |

**套用风格 skill 的准则（红线/适用项）**

| 准则 | 本方案落地 |
|---|---|
| 不重写、在既有栈上增量 | 只加 ⚙、抽屉、展开区；面板结构、消息流、来源交互全不动 |
| 数据用等宽/表格数字 | 耗时、命中数、行号、字节数一律 `font-variant-numeric: tabular-nums` |
| 字重不只有 400/700 | 层级用 400 / 500 / 600（标题 500、强调 600） |
| 必须有 focus ring | 所有可交互元素有可见聚焦环（无障碍硬要求） |
| 交互有过渡（150–300ms） | 抽屉 240ms、按钮态 160ms、开关 180ms；只用 `transform`/`opacity`/`background` |
| 按钮有按下反馈 | `transform: scale(.96)` |
| 不许有 loading / empty / error 缺口 | 保存中、保存失败、工具失败、空工具列表都有专门呈现 |
| 错误文案说人话、无感叹号、无 "Oops" | 「保存失败，请重试」/「文本不能为空」/「参数不是合法 JSON」 |
| 圆角分级 | 容器 16px（抽屉/卡片）、控件 8px（按钮/输入）、内层 6px（徽标） |
| 文案 sentence case | 中文同理：短句、直陈，不用「请点击此处」这类冗余 |

## 5. 响应式

| 断点 | 行为 |
|---|---|
| ≥1400px | 面板常驻，配置抽屉 420px 右侧滑入 |
| 1100–1400px | 面板变浮层（既有阈值，**未校准，属既有遗留项**）；抽屉仍 420px |
| <1100px | 抽屉**全宽**（`width: 100%`），保存栏吸底 |

## 7. demo

`demo/chat-tools-config/index.html`（**单文件自包含**，128KB，双击即开）

> **为什么 `ki.css` 是内联而不是 `<link>`**（2026-09-30 修复）：
> 预览面板是把**单个 HTML** 从 `static-html/<hash>/` 路由下发的，相对路径 `../../web/src/styles/ki.css` **取不到** →
> 整页裸奔（已实测）。故把真实 `ki.css` **原样内联**进 `<style>`（无外部 `url()` 依赖，仅一处 data:URI 内联 SVG，安全）。
> **维护约定**：改样式请改源文件 `web/src/styles/ki.css`，再重新生成 demo 的内联块；demo 内联块不要单独改。
