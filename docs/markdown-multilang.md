# Markdown 多语言代码块（`::: code-group`）

> **面向**：写知识库文档的人（§1–§3、§6–§8）、读文档的人（§4）、维护渲染器的人（§9）。
>
> **一句话**：把「同一段功能的多语言实现」收成一个可切换的代码块组，读者按自己的语言背景一键切换，不用在几段代码之间来回找。

---

## 1. 写作者：最小可用写法

````markdown
::: code-group

```python [Python]
def fib(n: int) -> int:
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

```ts [TypeScript]
export function fib(n: number): number {
  let [a, b] = [0, 1];
  for (let i = 0; i < n; i += 1) [a, b] = [b, a + b];
  return a;
}
```

:::
````

| 要素 | 写法 | 说明 |
|---|---|---|
| 组开始 / 结束 | `::: code-group` … `:::` | **顶格**、单独成行；组标记与代码块之间建议留空行（不强制） |
| 一个语言 | 标准围栏代码块 | 组内至少 **2 个** |
| 标签 | 语言后紧跟 `[显示名]` | 省略时标签 = 语言名 |
| 默认展开 | 组内第一个 | 读者若设了首选语言，则改为展开命中那一门（§4） |

## 2. 语言名 vs 标签，各管什么

- **语言名**（info string 的第一个词，如 ` ```python `）：决定「这是哪门语言」——用于读者偏好匹配、以及渲染出的 `language-*` 类名。**请务必写对**。
- **`[显示名]`**：只决定**标签上显示的文字**，可以带版本或场景，如 `[Python 3.12]`、`[Windows PowerShell]`。

```markdown
```py [Python 3.12]      ← 语言名 py（归一到 python），标签显示 “Python 3.12”
```

## 3. 三条降级（都不会报错，**内容一个不丢**）

| 情况 | 渲染结果 |
|---|---|
| 容器**没写**结束的 `:::`（如 AI 流式输出到一半） | 整段按「段落 + 独立代码块」渲染；补上 `:::` 后自动变成可切换的组 |
| 组内混进了**非代码块内容**（正文、表格、图片…） | 整组降级为普通内容，正文与代码块都在 |
| 有效代码块**少于 2 个**（含空块被丢弃后只剩一个） | 按普通代码块渲染 |

> 降级时 `::: code-group` 与 `:::` 这两行会**以正文形式显示出来** —— 这是该语法的固有代价，不是渲染器坏了。

## 4. 读者：设置「首选代码语言」

入口在**左侧栏底部**（主题按钮旁边，尖括号图标）：

- 展开后点一门语言即生效；已打开的文档**立即**换成这门语言，不用刷新
- 偏好**跨 scope、跨文档**生效（它是读者的属性，不是文档的属性）
- 组里**没有**你选的语言 → 照旧展示第一个，不提示、不报错
- 预置 20 门常见语言；覆盖不到的（`haskell`、`lua`…）用浮层底部的输入框手填
- 「不指定」= 恢复默认行为（每组展示第一个）
- **手动切换标签不会写回偏好**（否则就不叫默认了）—— 刷新或重进文档即回到偏好

**语言别名**：以下写法被视为同一门语言，偏好里选任一种都能命中。

| 规范名 | 也接受 |
|---|---|
| `python` | `py`、`python3`、`pyi` |
| `typescript` | `ts`、`tsx` |
| `javascript` | `js`、`jsx`、`mjs`、`cjs`、`node`、`nodejs` |
| `bash` | `sh`、`shell`、`zsh`、`console` |
| `css` | `scss`、`less` |
| `go` | `golang` |
| `csharp` | `cs`、`c#` |
| `yaml` | `yml` |
| `ruby` | `rb` |
| `dockerfile` | `docker` |

其余语言按小写精确匹配；`java` **不会**误配 `javascript`（不做前缀包含匹配）。

## 5. 完整示例集

### 5.1 命令的跨平台写法（技术文档里最高频）

````markdown
::: code-group

```bash [Linux / macOS]
export KI_CONFIG_PATH="$HOME/.ki/config.yaml"
```

```powershell [Windows PowerShell]
$env:KI_CONFIG_PATH = "$env:USERPROFILE\.ki\config.yaml"
```

```cmd [Windows CMD]
set KI_CONFIG_PATH=%USERPROFILE%\.ki\config.yaml
```

:::
````

### 5.2 省略标签，用语言名当标签

````markdown
::: code-group

```go
func Fib(n int) int { /* … */ }
```

```rust
fn fib(n: u32) -> u32 { /* … */ }
```

:::
````

### 5.3 同一文档多个组（彼此独立）

再写一组 `::: code-group` 即可，组之间互不影响；每组各自记住自己的切换状态。

## 6. 禁止用法

| ❌ 不要这样 | 为什么 |
|---|---|
| 把**非等价**内容放进同一组（如「方案 A / 方案 B」） | 切换语义是「同一件事的不同写法」，会让人以为二者等价 |
| 把 mermaid / 表格 / 正文段落放进容器 | 容器内**只放代码块**；需要图文混排就分开写 |
| 只放一个代码块 | 没有可切换的对象，直接用普通代码块 |
| 用本语法做「长代码折叠」「日志片段折叠」 | 语义不同（那是折叠，不是语言变体） |
| 组内代码块不写语言标识 | 标签退化成「代码」，读者无法辨认，偏好也匹配不上 |
| 嵌套 `::: code-group` | 不支持；需要分层就拆成多个组 |
| 标签里写 `]` | 标签以第一个 `]` 结束 |
| 行高亮等扩展语法（` ```js{1,3} `） | 不支持，会被当作语言串的一部分 |

## 7. 在其他 Markdown 阅读器里的表现

| 载体 | 表现 |
|---|---|
| **ki 知识库界面** | 完整功能：标签条 + 切换 + 按偏好展开 |
| **GitHub / VSCode / Typora 等** | `:::` 两行会以**字面文本**显示出来，里面的代码块照常高亮 —— 可读，但难看。属该语法的固有代价 |

## 8. 作者自查清单

- [ ] `::: code-group` 与 `:::` 都**顶格**、单独成行
- [ ] 组内至少 2 个代码块，且**每个都标了语言**
- [ ] 各块**功能等价**，只是语言不同
- [ ] 标签能一眼区分（有歧义时带版本或场景，如 `[Python 3.12]`）
- [ ] 组内没有正文、图片、表格、mermaid
- [ ] 复制任一语言的内容能独立跑通（不依赖另一种语言的上下文）

## 9. 维护者：实现在哪

| 关注点 | 位置 |
|---|---|
| 容器解析与渲染 | `web/src/components/MarkdownPreview.tsx` 的 `codeGroupExtension()`（含三条降级约束的注释） |
| 标签解析 / 语言别名 / 匹配算法 | `web/src/lib/codeLangPreference.ts` |
| 切换交互（点击、←/→、Home/End） | `MarkdownPreview.tsx` 的「多语言代码块切换」effect |
| 样式 | `web/src/styles/ki.css` 的 `.ki-code-group` / `.ki-code-tab` / `.ki-code-panel` 段 |
| 设置入口 | `web/src/components/CodeLangSelect.tsx`（Portal + 测量定位，见文件头注释） |
| 测试 | `web/test/code-group.test.mjs`、`web/test/code-lang-preference.test.mjs` |

**几个改起来容易踩的点**（都在源码注释里写了原因）：

1. 结束标记的查找必须**按行扫描并跳过围栏内部** —— 代码内容里出现 `:::` 行是合法的，用正则直接找会把容器提前截断。
2. 代码 `pre` 与 mermaid 图块移进 `.ki-code-panel` 后，原先那两条**直接子选择器**（`.ki-code-block > pre` / `> .ki-mermaid`）不再命中，需要按同口径补面板内规则。
3. 「首选语言」进 `MarkdownPreview` 的 `html` 依赖 ⇒ 偏好变化会重算整份文档；`renderMarkdownBlocks`（AI 对话链路）的 html 复用判据**不含偏好**，调用方传偏好时必须同时传空 `previous`。
4. 文档内查找会**跳过未显示的语言**（不可见内容不该参与命中计数）；切换语言后留在旧面板里的高亮目前不会自动重算，重新输入查找词即恢复。
