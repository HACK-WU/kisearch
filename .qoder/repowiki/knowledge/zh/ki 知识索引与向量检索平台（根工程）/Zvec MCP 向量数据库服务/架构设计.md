模块采用单包 `zvec_mcp` 结构：`server.py` 通过 `FastMCP` 实例注册所有 MCP `@tool`（集合/文档/查询/索引/AI 扩展）和 `@resource`（`zvec://collections`、`zvec://collection/{name}`），是对外暴露的唯一入口；`schemas.py` 集中定义全部 Pydantic v2 输入模型（含使用 `Annotated[... | ...] + Field(discriminator="type")` 实现的联合参数类型，如 HNSW/Flat/IVF/Invert 索引参数）；`types.py` 仅声明共享枚举（`ResponseFormat`、`DataTypeEnum`、`MetricTypeEnum`、`QuantizeTypeEnum` 等）；`utils.py` 维护进程内全局 `_open_collections` 字典作为会话级集合缓存，并提供 zvec 类型字符串到枚举的转换、统一错误格式化、文档列表 JSON/Markdown 双格式输出。依赖方向单向：`server → schemas/types/utils → zvec`，AI 扩展（OpenAI Dense Embedding）在运行时按需 `import zvec.extension.OpenAIDenseEmbedding` 以避免冷启动开销。构建由 `pyproject.toml` 配置，使用 hatchling+hatch-vcs 从 Git tag 动态生成版本，并通过 `[project.scripts]` 暴露 `zvec-mcp-server` CLI 指向 `zvec_mcp.server:mcp.run`，`__main__.py` 提供 `python -m zvec_mcp` 等价入口。CI/Release 流水线位于 `.github/workflows/ci.yml` 与 `release.yml`。
