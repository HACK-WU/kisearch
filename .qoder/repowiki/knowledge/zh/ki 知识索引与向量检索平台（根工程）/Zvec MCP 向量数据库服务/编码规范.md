- 每个 MCP 工具函数均使用 `@mcp.tool(name=..., annotations={readOnlyHint, destructiveHint, idempotentHint, openWorldHint})` 装饰，并在 docstring 中写明 Use when / Don't use when 示例。
- 所有工具函数统一采用 `try/except Exception as e: return handle_error(e)` 的错误处理模式，返回人类可读的错误字符串而非抛出异常。
- 输入参数一律使用 Pydantic v2 `BaseModel` + `Field(...)` 描述，并通过 `Annotated[T1 | T2, Field(discriminator="type")]` 实现多态参数（如索引参数、向量字段参数）。
- 集合生命周期通过进程内全局 `_open_collections` 字典进行会话级缓存，所有写操作先调用 `get_collection(collection_name)` 校验存在性再执行。
- 对外响应统一通过 `json.dumps(..., indent=2)` 或 `format_doc_list(docs, ResponseFormat.MARKDOWN|JSON)` 两种格式输出，保持 JSON/Markdown 双通道一致。
- 对 zvec 枚举类型（DataType/MetricType/QuantizeType）的字符串到枚举转换集中在 `utils.py` 的 `get_zvec_*_type` 函数中，避免在各工具中散落 `getattr` 逻辑。
