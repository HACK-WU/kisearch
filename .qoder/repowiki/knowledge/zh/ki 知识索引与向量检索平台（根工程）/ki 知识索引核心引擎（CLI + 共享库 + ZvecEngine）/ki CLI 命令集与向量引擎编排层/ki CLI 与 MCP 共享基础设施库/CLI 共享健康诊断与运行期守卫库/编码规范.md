- 对外暴露结构化报告类型（如 `HealthItem`/`HealthReport`、`InterruptMark`、`ImportLock`）配合 `status: 'pass'|'warn'|'fail'` 三元状态，便于统一渲染与统计。
- 关键文件写入采用「先写 .tmp 再 `renameSync`」的原子替换模式（中断标记、导入锁），避免并发下读到半写文件。
- 可选或外部依赖的检查（statfs、fs.watch、embedding 请求）采用 try/catch 降级：失败时静默跳过或返回默认值，不阻断主流程启动。
- 错误通过自定义 Error 子类携带 `code` 字段（如 `PreflightError` 的 `DIR_NOT_WRITABLE`/`DISK_INSUFFICIENT`），由调用方统一映射为 JSON 错误输出。
- 路径构造统一基于 `getKbDir(scope)` / `getVectorDir(config)` / `KI_ROOT` 等集中 accessor，避免在多处拼接 scope 路径。
