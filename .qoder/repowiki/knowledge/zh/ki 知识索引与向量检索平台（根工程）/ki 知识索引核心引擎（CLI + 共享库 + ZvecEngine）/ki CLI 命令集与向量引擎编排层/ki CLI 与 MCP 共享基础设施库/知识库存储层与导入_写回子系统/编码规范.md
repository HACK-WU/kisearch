- 所有 JSON 持久化统一走 `walWrite`，先写 `.tmp` 再 `renameSync` 原子替换，避免多进程并发覆盖导致的数据损坏。
- 对外部输入（relation 名、sourceDir、scope）进行前置校验，非法值直接拒绝并返回结构化错误信息而非抛出未分类异常。
- 导入与写回操作采用幂等设计：同 sourcePath 重跑覆盖、不同 sourcePath 同名 relation 跳过冲突，并通过 `isUnsafeRelationName` 统一防御路径穿越。
- 长耗时阶段使用 `logPhaseStart`/`logProgress`/`logPhaseDone` 输出进度，避免 TTY 下长路径叠加造成显示乱码。
- 缓存类模块（如 relation-map）以模块级 Map 维护状态，并以 mtime+size+TTL 三重条件触发懒重建，读取失败时降级为安全空结果。
