模块按职责划分为四个单向依赖的子层：
- 持久化层（store.ts + wal.ts）：`walWrite` 通过 `.lock` 文件锁（`fs.openSync(..., 'wx')` + `SharedArrayBuffer`/`Atomics.wait` 自旋等待，30s 陈旧锁抢占）+ `.tmp` 临时文件 + `fs.renameSync` 实现跨进程原子写入；`readJson`/`writeJson` 在读写时注入 `version`/`updatedAt` 并做版本兼容检查；`store.ts` 在此基础上提供 `ensureScopeDir`、`initScope`（从 `_template/` 复制模板）、`readGroupIndex`（自动迁移旧 `roots→groups` 格式及 relations-cache key 前缀）。
- 导入层（import.ts）：`handleDirectImport` 是统一入口，按 Phase 2~5 串行执行——扫描 Markdown → 清洗+切分 → 调用 `bulkVectorize`/`vector-client` 向量化 → 构建 Group 树 → 写 `relations-cache.json` + local KB → 记录 source 块；通过 `acquireImportLock`/信号捕获实现中断可恢复与并发互斥，支持 --no-vector 仅写 KB 层的降级模式。
- 写回层（wiki-sync.ts）：`writeBackToWiki`/`backfillWiki` 依据 group-index source 或 config 解析目标目录，生成 Markdown 并落盘，支持 autoBackfill 自动补齐历史关系，失败不抛异常仅返回结果对象。
- 反查层（relation-map.ts）：模块级单例 Map 缓存 `memoryId → {group, relation}`，以 relations-cache 的 mtime+size+TTL 三重条件触发懒重建，读取失败时降级为安全空结果。
所有写操作均经 `walWrite` 保证原子性，读路径通过 `readJson` 做版本兼容与损坏保护。
