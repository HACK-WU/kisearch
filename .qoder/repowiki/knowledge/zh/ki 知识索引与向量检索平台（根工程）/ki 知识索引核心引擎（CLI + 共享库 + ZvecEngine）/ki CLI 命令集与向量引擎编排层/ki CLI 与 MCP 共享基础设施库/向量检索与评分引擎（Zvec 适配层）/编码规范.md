- 所有引擎操作统一经 `withEngine` 包装，自动处理在途计数、空闲续期与 worker 不可用自愈重试，禁止直接 await getEngine() 调用底层方法。
- tag 写入前一律经 `normalizeTag` 转小写，查询时 tag 过滤也先 normalize，实现大小写无关的相等匹配。
- doc id 通过 `generateDocId(text, scope, tag)` 用 sha256 截 32 生成，保证同 scope+text+tag 幂等 upsert，不同 tag 产生独立 docId 以支持多标签。
- 批量向量化采用固定批次大小（VECTORIZE_BATCH_SIZE=200）切片提交，批间调用 `logProgress` 输出进度，失败条目累积到 errors 不中断整体流程。
- 评分相关函数（calculateScore、recordUse、partitionByScore、boundaryDecay）均为纯函数，输入不变、返回新对象，便于单元测试与组合复用。
- 范围校验区分业务白名单（resolveScope）与管理面字符校验（validateScope），管理命令如 vectorListDocs/vectorDeleteScope 一律使用 validateScope 以绕过 strict 白名单限制。
