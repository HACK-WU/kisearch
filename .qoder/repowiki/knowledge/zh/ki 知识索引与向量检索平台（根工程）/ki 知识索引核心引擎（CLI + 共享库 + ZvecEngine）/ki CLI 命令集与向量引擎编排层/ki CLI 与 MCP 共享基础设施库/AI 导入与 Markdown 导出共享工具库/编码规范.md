- 工具函数采用纯函数 + 显式 export 的形式组织，模块内不维护全局状态。
- 控制台输出统一通过 process.stderr.write 直接写入，禁止使用 console.log，以避免污染 stdout 的 JSON 结果。
- 面向用户的文本在 TTY 下使用回车覆盖（\r）实现单行进度条，在非 TTY 下退化为逐行输出以保证可读性。
- YAML frontmatter 值通过 yamlSafe 进行特殊字符转义，确保 groupPath/relation/exportedAt 等字段不会破坏 YAML 语法。
- 网络地址判定函数对输入执行 trim().toLowerCase() 后再做匹配，统一大小写与空白处理。
