本模块由四个相互独立的纯函数式工具文件组成，无运行时依赖、无状态对象，仅通过显式 export 暴露 API 供上层 CLI 命令（export.ts、wiki-sync.ts 等）调用：
- ai-results.ts 定义 ScanResultEntry 接口及 deriveGroupPath 路径推导函数，作为导入条目的最小数据契约。
- markdown-gen.ts 提供 yamlSafe 与 generateMarkdown，统一 KB 导出与 wiki 写回的 YAML frontmatter 格式，确保两者一致。
- progress.ts 封装 apt install 风格的控制台进度展示，所有输出强制写入 process.stderr，避免污染 stdout 上的 JSON 结果；同时区分 TTY/非 TTY 行为以支持管道重定向。
- net-addr.ts 提供 isLoopbackHost / isLoopbackAddr，用于 MCP HTTP 鉴权时判断请求来源是否为本地回环地址（含 IPv4/IPv6/IPv4-mapped-IPv6）。各文件之间不互相引用，保持正交可复用。
