- 每个文件同时暴露 `executeXxx(params)` 纯函数（返回 `{ ok: true/false, ... }` 联合类型）供 MCP 调用，并在文件末尾用 commander 注册同名 CLI 子命令。
- 通过 `_isMain` 闭包检测 `process.argv[1]` 与 `import.meta.url` 是否匹配，仅在直接运行时执行 `program.parse()`，避免被 import 时副作用。
- 所有错误路径统一输出 `{ ok: false, error: string, hint?: string }` 形式的 JSON 结果，而非抛异常。
- 涉及向量引擎的操作统一通过 `ensureVectorAvailable` 探测可用性，并在 finally/块尾调用 `closeEngine()` 释放 LOCK。
- Group 路径解析统一走 `resolveGroupPath` 配合 `findContainer`，先尝试精确父容器再 fallback 到自动补全路径。
- 命令行选项解析集中到 `parseCliOpts` 类辅助函数中，对数值型参数（如 depth、hotCount）做越界回退并输出警告。
