- 每个命令文件采用「CLI 定义 + 纯函数 executeXxx + 共享类型」三段式结构，业务逻辑集中在 executeXxx 中以便 CLI 与 MCP 复用。
- 对外统一返回联合类型 `{ ok: true; ... } | { ok: false; error: string; degraded?: boolean }`，失败路径通过 `degraded` 标记降级状态。
- 所有命令在 action 中先通过 `resolveScope(loadConfig(), opts.scope)` 解析 scope，再调用 ensureVectorAvailable 检测向量服务可用性后再执行业务。
- 数值型参数统一通过 `parseIntArg` / `parseFloatArg` 解析并带最小值校验，避免 NaN 静默传播。
- 命令末尾统一调用 `closeEngine()` 释放向量引擎资源，并在 `!result.ok` 时 `process.exit(1)` 退出。
- 文件末尾使用 `_isMain` IIFE 配合 `import.meta.url` 判断是否直接运行，从而保证被 import 时不会触发 commander.parse()。
