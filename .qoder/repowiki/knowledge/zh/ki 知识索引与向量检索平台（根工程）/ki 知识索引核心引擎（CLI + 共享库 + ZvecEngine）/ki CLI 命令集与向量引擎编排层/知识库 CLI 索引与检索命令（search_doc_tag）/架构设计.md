三个文件各自独立实现一个 commander 子命令入口（search.ts、doc.ts、tag.ts），遵循统一的「CLI 定义 + 纯函数 executeXxx + 共享类型」分层：
- 顶层通过 `Command` 注册子命令与选项，action 中先调用 `resolveScope(loadConfig(), opts.scope)` 解析 scope，再调用 `ensureVectorAvailable()` 检测向量服务可用性。
- 中间层暴露纯函数 `executeSearch` / `executeDocList` / `executeDocDelete` / `executeTagList`，仅依赖 `./lib/vector-client.js`、`./lib/config.js`、`./lib/cli-args.js` 等底层库，供 CLI 与 MCP 复用。
- 底层统一通过 vector-client 访问 zvec/vector 引擎；search.ts 额外依赖 `./lib/relation-map.js` 与 `./lib/store.js`，在命中结果上反查 relations-cache 以回填 group/relation 并可选拉取 local KB 原文（REQ-09）。
- 所有命令执行结束后调用 `closeEngine()` 释放 engine 资源，并通过 `_isMain` IIFE 配合 `import.meta.url` 判断是否直接运行，确保被 import 时不自动触发 `program.parse()`。
- 对外统一返回联合类型 `{ ok: true; ... } | { ok: false; error: string; degraded?: boolean }`，失败路径通过 `degraded` 标记降级状态，CLI 侧在 `!result.ok` 时 `process.exit(1)` 退出。
