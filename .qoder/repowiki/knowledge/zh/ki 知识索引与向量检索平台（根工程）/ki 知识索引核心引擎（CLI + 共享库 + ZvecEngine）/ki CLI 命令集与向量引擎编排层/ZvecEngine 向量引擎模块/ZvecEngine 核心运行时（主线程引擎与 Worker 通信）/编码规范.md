- 对外暴露的公共 API 集中在 `index.ts` 统一 re-export，内部实现（如 `ZvecEngineProxy`、`EmbeddingProvider`、Worker 系列）不直接导出，保持门面模式。
- 所有业务异常继承 `ZvecEngineError` 并设置 `code`/`data`/`cause`，通过 `ERROR_CONSTRUCTORS` 映射表在跨线程序列化/反序列化时恢复精确异常类型。
- 向 worker 传递大对象时使用 `Float32Array` 并通过 `collectTransferables` 收集 buffer 放入 postMessage transfer list，实现零拷贝传输。
- 异步请求采用「id + pending Map」模式：发送前分配 UUID，响应到达后按 id 查找并 resolve/reject，crash 时统一 rejectAllPending。
- 生命周期状态用有限状态机（`State` 联合类型）驱动，所有方法在进入关键路径前检查 state 并抛出对应 `WorkerUnavailableError`。
- 批量操作按固定批次大小切分（`EMBED_BATCH_SIZE=64`、`DEFAULT_WRITE_BATCH_SIZE=100`），使失败粒度可控且与下游 provider 的 HTTP 调用边界对齐。
