- 对外 API 仅通过 index.ts 显式 re-export，Worker 系列与 Embedding 内部实现标注 @internal 不暴露给调用方
- 所有跨进程数据交换使用 worker-protocol.ts 中定义的 Payload 类型，禁止在主/从之间传递未声明结构
- 错误处理统一收敛到 errors.ts 的类型化异常族，engine.ts 在边界处将底层错误转换为 v5 契约约定的异常并附带 data 上下文
- schema/validator.ts 与 schema/builder.ts 配合，在 create/open 时分别做输入校验与持久化 Schema 构建，保证集合元数据一致性
- Filter 必须先经 filter/compiler.ts 编译为 SQL 片段并受 allowedFields 白名单限制后才可下发到 worker
