顶层 src/ 采用「扁平命令 + 共享库 + 隔离引擎」三层结构：
- 命令层（src/*.ts）：每个文件即一个可执行 Node 脚本，使用 commander 注册子命令与选项，仅负责参数解析、调用编排与 JSON 错误输出，不内嵌业务逻辑。
- 共享库层（src/lib/*）：集中实现 Scope/Group 解析、WAL 存储、向量客户端、导入导出、进度条、中断处理、MCP stdio/HTTP 传输等跨命令复用的能力；mcp-tools 将同一组领域模型同时暴露为 MCP 工具与 HTTP API，使 CLI 与 MCP 共享契约。
- 引擎层（src/zvec-engine）：ZvecEngine 门面编排 schema 校验、embedding provider、filter 编译、检索路由，并通过 worker-protocol 将 embedding/filter/search 等重计算隔离到独立 worker 进程，主进程仅做协议编解码。
各命令之间无直接耦合，仅通过 lib 层契约通信；zvec-engine 作为唯一向量索引访问点，避免命令直接操作底层索引。
