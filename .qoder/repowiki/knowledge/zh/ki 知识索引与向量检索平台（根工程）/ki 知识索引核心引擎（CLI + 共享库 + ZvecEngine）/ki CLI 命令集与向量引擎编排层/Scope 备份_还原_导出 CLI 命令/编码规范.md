- 每个 CLI 文件顶部以 JSDoc 注释声明 `ki <cmd>` 用法，并在 -h/--help 命中时直接 console.log 帮助文本后 process.exit(0)。
- 参数校验统一通过 lib/cli-args.detectUnknownFlags 传入已知 flag 白名单与带值 flag 列表，未知参数回退到帮助文本。
- 成功路径统一通过 output({ ok: true, action: '<action>', ... }) 输出格式化 JSON 到 stdout，错误路径通过 toErrorPayload(err) 输出 { ok: false, error, code } 并 exit(1)。
- 破坏性操作（restore 覆盖、export 覆盖非空目录）采用「先展示总览/提示 → 要求 --yes 重新执行」的非交互确认模式，绝不阻塞等待用户输入。
- 在涉及磁盘写入前调用 lib/preflight.checkWritable / checkDiskSpace 做预检，捕获 PreflightError 并以统一错误结构返回。
- scope 合法性统一通过 validateScope(scope) 校验，数据目录路径通过 getScopeDataDir/getBackupDir 等配置函数解析，避免硬编码路径。
