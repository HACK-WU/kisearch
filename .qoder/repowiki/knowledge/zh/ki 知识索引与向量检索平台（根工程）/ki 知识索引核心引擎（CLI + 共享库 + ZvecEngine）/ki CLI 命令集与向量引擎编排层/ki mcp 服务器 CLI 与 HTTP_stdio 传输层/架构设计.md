模块由三个文件构成清晰的职责分层：
- `src/mcp-server.ts` 是 CLI 入口，通过 `startMcpServer()` 解析 `ki mcp` 子命令（`stop` / `token` / `restart` / `--status` / 默认 stdio），完成启动守卫（HTTP 单例复用、stdio 与 HTTP 互斥检测）、健康预检、版本守卫、向量库空闲释放，再分派到 stdio 或 HTTP 路径。
- `src/lib/mcp-http.ts` 基于 Node 内建 `http` + `@modelcontextprotocol/sdk` 的 `StreamableHTTPServerTransport` 构建 HTTP 服务，按会话创建独立 `McpServer`，共享模块级 vector-client 单例；内置 `/healthz`、可选静态页面（`--web`）、Bearer Token 鉴权（回环免鉴权、非回环强制）与 DNS rebinding 保护，并通过 `~/.ki/mcp-http.lock` 实现幂等单例守护。
- `src/lib/mcp-stdio-lock.ts` 以「每实例独立 lock 文件」`~/.ki/mcp-stdio-<pid>.lock` 登记 stdio 实例，支持多实例共存、陈旧锁自动清理（signal 0 探测 EPERM）以及 `acquire/release/listLive` 接口供 stop/restart/status 定位进程。
依赖方向单向：mcp-server → mcp-http + mcp-stdio-lock + mcp-tools/* + mcp-token；HTTP 层通过延迟 `import('./mcp-http-api.js')` 避免初始化重依赖链。
