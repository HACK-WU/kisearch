- 每个 CLI 子命令以独立 Node 脚本组织，文件顶部声明 #!/usr/bin/env node 并使用 commander 的 Command() 实例注册子命令与选项。
- 错误输出统一采用 JSON 契约 { ok: false, error, code? }，通过 lib/cli-args.ts 的 failJson/toErrorPayload 输出并 exit(1)。
- 未知参数检测通过 detectUnknownFlags 配合 Levenshtein 建议提示，对拼写错误的 --flag 给出最接近的正确参数。
- 数值型参数统一用 parseIntArg/parseFloatArg 解析，非法值回退默认值并在 stderr 打印警告。
- 跨命令共享的能力一律从 src/lib 引入，命令脚本本身只负责参数解析与编排，禁止重复实现业务逻辑。
- 向量操作全部经由 zvec-engine 的 ZvecEngine 门面，embedding/filter/search 细节被隔离到独立 worker 进程，主进程不直接操作底层索引。
