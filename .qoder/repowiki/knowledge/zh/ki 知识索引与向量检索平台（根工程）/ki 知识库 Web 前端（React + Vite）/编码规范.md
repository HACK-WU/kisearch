- API 层通过统一的 `req<T>(path, init?)` 封装 fetch，统一设置 `Content-Type: application/json`，并在非 2xx 或无 JSON body 时抛出带 `error` 字段的 Error。
- 所有后端接口响应均定义对应 TypeScript 接口（如 `HealthResponse`、`DocListResponse`、`UploadResponse` 等），并作为函数返回类型严格约束。
- 跨页面共享的全局状态（scope、theme）通过 React Context + localStorage 持久化实现，并提供自定义 hook（`useScope`、`useScopeValue`、`useTheme`）暴露读写能力。
- 页面路由采用 react-router-dom v7 的嵌套 Route 模式，所有页面都包裹在 `AppShell` 布局下，通过 `index` 与 `path` 子路由注册。
- 组件与页面文件使用 kebab-case 目录名（如 `components/`、`pages/`、`layouts/`），内部导出命名 PascalCase 的函数式组件。
- 样式采用单一 CSS 文件 `styles/ki.css` 配合 BEM 风格类名（如 `ki-sidebar__header`、`ki-nav-item--active`），通过 `body.dataset.theme` 切换明暗主题。
