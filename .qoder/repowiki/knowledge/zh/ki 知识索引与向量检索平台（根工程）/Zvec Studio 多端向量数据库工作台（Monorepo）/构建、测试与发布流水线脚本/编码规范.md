- 每个 Python 脚本以 `if __name__ == "__main__": raise SystemExit(main())` 作为入口，并提供 `parse_args(argv=None)` 以便单元测试注入参数。
- 脚本通过 `REPO_ROOT = Path(__file__).resolve().parent.parent` 定位仓库根，再拼接 `apps/*` 子项目路径，避免硬编码绝对路径。
- 平台差异通过 `_is_windows()` / `_is_macos()` / `_is_linux()` 等辅助函数判断，而非直接比较 `platform.system()`。
- Shell 脚本统一使用 `set -uo pipefail` 并以 `FAILURES`/`GATE_FAILURES` 计数器累计失败，最终根据计数返回 0/1 退出码。
- 质量类脚本在 `artifacts/` 下输出结构化 JSON（如 `quality-metrics.json`、`pre-release-result.json`），便于 CI 消费。
- Workflow 中的多平台/多版本矩阵通过 `strategy.matrix.include` 声明 runner、slug、python-version 等字段，并在步骤中使用 `${{ matrix.* }}` 引用。
