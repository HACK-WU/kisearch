模块以三个独立的 Starlette `BaseHTTPMiddleware` 构成核心：`trace_id.py` 通过 `contextvars.ContextVar` 在请求生命周期内维护 ULID 形式的 `traceId`，并透传到响应头 `X-Trace-Id`；`logging.py` 基于标准库 `logging` 在每次请求后输出包含 traceId、方法、路径、状态码、耗时和客户端 IP 的单行 JSON 记录；`error_handler.py` 通过 `app.add_exception_handler` 注册对 `ZvecStudioError`、`StarletteHTTPException`、`RequestValidationError` 及通用 `Exception` 的统一处理器，全部返回 `application/problem+json` 格式的 ORJSONResponse。三者依赖方向单向：logging 与 error_handler 均通过 `get_trace_id()` 读取 trace_id，trace_id 不依赖其他两个；`__init__.py` 作为包入口统一导出 `JsonLinesAccessLogMiddleware`、`TraceIdMiddleware`、`get_trace_id` 与 `register_error_handlers`，供上层 FastAPI 应用装配。
