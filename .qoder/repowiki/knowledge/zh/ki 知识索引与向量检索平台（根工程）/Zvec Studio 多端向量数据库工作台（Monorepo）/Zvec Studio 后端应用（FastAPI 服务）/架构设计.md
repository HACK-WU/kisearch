以 zvec_studio/main.py 中的 create_app() 为唯一装配点：在 app.state 上集中挂载 Settings、CollectionRegistry、AIFunctionRegistry、AIService、ConfigStore 与 SdkBackend 等进程级单例；按顺序注册 CORS → JsonLinesAccessLogMiddleware → TraceIdMiddleware 中间件链，并通过 register_error_handlers 将自定义异常统一转为 RFC 7807 Problem Details；随后将 routers/collections、documents、fs、searches、ai 以及 meta/diagnostics 路由挂载到统一的 api_prefix 下，并在存在 index.html 时提供 SPA 回退。routers 层仅依赖 deps.py 提供的 get_*_dep 从 request.app.state 注入共享状态，schemas 层作为请求/响应的 Pydantic 契约被所有路由共用，ai_service 与 ai_store 由 main 启动时完成内置函数种子注册，形成「配置→中间件→路由→服务/存储」的单向依赖流。
