模块由三个职责清晰的子文件组成：
- `ai_store.py` 实现 `AIFunctionRegistry`，以 `<data_dir>/ai_functions.json` 为唯一持久化载体，通过 `tempfile.mkstemp + os.replace` 原子写入并将文件权限设为 `0600` 保护 apiKey；所有 CRUD 方法通过 `RLock` 保证线程安全。
- `ai_service.py` 实现 `AIService`，作为面向 HTTP 端点的薄门面：根据配置类型（`DefaultLocalDenseConfig` / `BM25Config` / `Qwen*` / `OpenAIDenseConfig` 等）动态 `import` 并构造对应的 zvec SDK 扩展类（如 `DefaultLocalDenseEmbedding`、`BM25EmbeddingFunction`、`QwenReRanker`），并通过 LRU `OrderedDict` + 失败缓存（TTL 60s）缓存嵌入实例与 BM25 encoder；缺失依赖统一包装为 `AIDependencyMissingError`（HTTP 503），调用异常包装为 `AIFunctionInvocationError`（HTTP 500）。
- `registry.py` 实现进程内的 `CollectionRegistry`，维护已打开的 `zvec.Collection` 句柄（当前以 `CollectionHandle` 占位），供上层路由按名称查找。
依赖方向单向：`ai_service` → `ai_store`（读取配置）+ `zvec` SDK（运行时导入）；`ai_store` 与 `registry` 不互相引用，仅依赖共享的 `schemas` 与 `exceptions`。
