运行需先 `pip install -e apps/backend[dev]` 安装可编辑后端；开发模式 `pnpm --filter desktop tauri:dev` 会依次启动 Vite dev server → 自动 spawn Python sidecar → 打开 Tauri 窗口。生产打包分两步：`make package.sidecar` 冻结 sidecar 到 `binaries/zvec-studio-sidecar-<host-triple>`，再 `make package.desktop` 用 `tauri.bundle.conf.json` 构建多目标安装包（dmg/deb/AppImage/msi）。可通过 `ZVEC_SIDECAR_DISABLED=1` 跳过 spawn 以连接外部已运行的后端。
