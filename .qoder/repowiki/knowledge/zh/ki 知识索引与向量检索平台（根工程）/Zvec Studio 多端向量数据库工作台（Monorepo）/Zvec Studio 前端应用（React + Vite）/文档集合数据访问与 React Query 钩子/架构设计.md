模块按职责拆分为三层：`api.ts` 通过 `createDocumentsApi` 将后端 REST 端点（如 `/collections/:id/documents:browse`、`:upsert`、`:deleteBatch` 等）封装为强类型的 `DocumentsApi` 接口，所有请求体/响应类型直接复用 `@zvec-studio/api-client` 生成的 `components['schemas']`；`hooks.ts` 基于该 API 构建一组 React Query 钩子（`useDocumentsBrowse`、`useDocumentDetail`、`useInsertDocuments`、`useDeleteDocument`、`useUpsertDocuments`、`useUpdateDocuments`、`useDeleteDocumentsBatch`、`useDeleteDocumentsByFilter`），并通过统一的 `invalidateAfterWrite` 在写操作成功后失效浏览列表、详情行、集合摘要及全局集合缓存；`index.ts` 作为公共门面仅 re-export API 构造器、类型与 hooks，对外隐藏内部实现。依赖方向单向：hooks → api → ApiClient → 网络层，不反向引用 UI。
