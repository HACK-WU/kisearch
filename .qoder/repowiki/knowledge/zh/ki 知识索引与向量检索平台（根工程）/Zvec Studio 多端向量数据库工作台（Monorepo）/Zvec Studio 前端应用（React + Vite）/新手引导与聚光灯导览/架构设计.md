模块以 React 组件 + 自定义 Hook 的形式组织：`OnboardingFlow.tsx` 实现一个基于 `Dialog` 的五步引导流程，首步集成最近打开的 Collection 列表（复用 `@/features/collections` 的 `useListRecent/useForgetRecent/useClearRecent`）；`SpotlightTour.tsx` 是一个通用的高亮导览组件，通过 `createPortal` 将遮罩、聚光灯和浮动提示框挂载到 `document.body`，根据目标元素的 `getBoundingClientRect` 计算定位并支持 `right/left/top/bottom` 四种放置位置，同时过滤 `optional` 步骤且监听 resize/scroll 重算布局；`hooks.ts` 暴露 `useOnboarding`，使用 `localStorage`（key 为 `zvec-studio:onboarded`）持久化完成状态，并提供 `start/dismiss/reset` 命令式 API；`index.ts` 作为统一导出入口，对外暴露两个组件、Hook 及类型。依赖方向单向向下：组件仅依赖 UI 基础组件与 collections 功能，不反向引用上层路由或状态。
