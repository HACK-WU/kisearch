- 所有用户可见文案通过 `react-i18next` 的 `t()` 函数读取 i18n key，避免硬编码字符串。
- 交互元素统一添加 `data-testid` 属性（如 `zv-onboarding-next`、`zv-tour-skip`），便于测试定位。
- 样式类名采用 BEM 风格命名空间前缀 `zv-onboarding__*` / `zv-tour-tooltip__*`，并通过 CSS 文件单独管理。
- 组件以受控形式暴露 `open` + `onDismiss` props，内部自行维护步骤状态，由调用方控制生命周期。
- 本地存储读写封装为 try/catch 包裹的辅助函数，忽略浏览器禁用 storage 等异常。
