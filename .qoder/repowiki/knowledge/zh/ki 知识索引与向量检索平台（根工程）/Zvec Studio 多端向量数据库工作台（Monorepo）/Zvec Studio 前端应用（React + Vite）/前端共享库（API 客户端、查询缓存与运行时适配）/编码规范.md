- 所有对外能力均通过工厂函数（`createApiClient`、`createQueryClient`、`createFsApi`）构造实例，便于测试时注入 mock 实现。
- 错误统一收敛为 `UserFacingError`（含 `code`、`messageKey`、`severity`、`traceId`），由 `mapProblem`/`mapUnknownError` 转换后向上抛出 `ApiError`。
- 运行时特性通过 `isTauri()` 守卫分支，Tauri 专属能力（侧车 URL、目录选择器、状态查询）在 Web 环境安全降级而非抛错。
- API 基地址在 `resolveApiBaseUrl()` 中一次性解析并缓存，避免重复探测 Tauri 侧车。
- TanStack Query 的错误通过 `QueryCache.onError` 上报到外部 `onError` 回调，并由 `meta.skipGlobalError` 标记允许局部处理。
- 对后端响应的处理区分 204（返回 `undefined`）与正常 JSON 响应，非 2xx 一律经 `mapProblem` 转为 `ApiError`。
