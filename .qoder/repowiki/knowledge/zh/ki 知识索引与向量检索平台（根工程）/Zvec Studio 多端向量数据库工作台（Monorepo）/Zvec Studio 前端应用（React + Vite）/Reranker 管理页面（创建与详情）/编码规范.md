- 所有用户可见文案通过 `useTranslation()` 配合 `pages.ai.reranker*` 或 `pages.aiFunctions.rerankers*` 命名空间下的 key 获取，避免硬编码字符串。
- 对后端的增删改查统一通过 `@/features/ai/hooks` 提供的 `useXxx` hooks（如 useCreateReranker/useUpdateReranker/useDeleteReranker）发起，并在 mutate 的 onSuccess/onError 回调中通过 `useToast().push` 反馈结果。
- Reranker 的配置以 JSON 文本形式在 `<textarea>` 中编辑，提交前使用 `JSON.parse` 校验并捕获异常后通过 toast 提示 invalidJson。
- 组件对外暴露的 props 使用 TypeScript interface 声明为 readonly，并将 open/close 等控制逻辑交由父组件持有状态。
- 按钮 loading 状态直接绑定到 hook 返回的 `isPending`，并在禁用态下阻止重复提交。
