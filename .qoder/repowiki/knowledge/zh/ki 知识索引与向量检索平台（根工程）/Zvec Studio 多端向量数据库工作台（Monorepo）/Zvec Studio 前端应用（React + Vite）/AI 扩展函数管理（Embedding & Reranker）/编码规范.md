- API 绑定通过 `createAiApi(client)` 工厂函数返回具名方法对象，每个后端端点对应一个 Promise 方法并透传 `AbortSignal`。
- React Query 的 query key 以稳定元组常量形式集中声明（如 `embeddingsListQueryKey`），detail key 使用 `(name) => ['ai', ..., name]` 工厂生成。
- 写操作 mutation 在 `onSuccess` 中调用 `invalidateQueries` 刷新对应 list 与 detail 缓存，删除场景改用 `removeQueries` 避免后续 refetch 产生 404。
- `:embed` / `:rerank` 这类执行型端点统一暴露为 mutation，不缓存也不触发 invalidation，体现“用户显式动作”的语义。
- 创建对话框采用「类型选择 + 原始 JSON textarea」模式，并通过 `*_TEMPLATES` 映射表预填充合法 JSON，由后端 schema 作为唯一真实来源。
- 错误处理统一捕获 `ApiError`，通过 i18n 的 `messageKey` 渲染消息，未知错误回退到 `errors.unknown` 文案。
