模块按 `features/ai`（可复用能力层）与 `pages/ai`（页面层）两层组织，依赖方向单向：页面 → features → api-client。
- `api.ts` 通过 `createAiApi(client)` 工厂封装 `/ai/embeddings` 与 `/ai/rerankers` 两组 REST 端点，定义 `AiApi` 接口并导出所有后端 schema 类型别名（`EmbeddingFunctionRecord`、`RerankerFunctionRecord`、`EmbedRequest`、`RerankRequest` 等），便于 MSW 驱动测试保持扁平结构。
- `hooks.ts` 基于 `@tanstack/react-query` 暴露稳定的 query key（如 `embeddingsListQueryKey`）和 CRUD + execute hook（`useListEmbeddings`、`useCreateEmbedding`、`useEmbed`、`useRerank` 等），其中 `:embed` / `:rerank` 作为 mutation 暴露且不缓存；写操作成功后通过 `invalidateQueries` 同步 list/detail 缓存，删除时改用 `removeQueries` 避免 404 闪烁。
- `utils.ts` 提供嵌入向量类型判别（dense/sparse）与维度/标签提取工具，仅依赖 `EmbeddingFunctionRecord.config`。
- `index.ts` 作为 barrel 统一对外暴露 API、hooks、query keys 与 utils。
- `pages/ai/AiFunctionsPage.tsx` 是 `/ai-functions` 路由入口，用 Tabs 切换 embeddings/rerankers 两个 Tab，每个 Tab 复用相同的 Table + Dialog + CreateDialog 布局；配置编辑采用原始 JSON textarea 并以 `EMBEDDING_TEMPLATES` / `RERANKER_TEMPLATES` 预填模板，避免前端表单与后端 schema 漂移。
