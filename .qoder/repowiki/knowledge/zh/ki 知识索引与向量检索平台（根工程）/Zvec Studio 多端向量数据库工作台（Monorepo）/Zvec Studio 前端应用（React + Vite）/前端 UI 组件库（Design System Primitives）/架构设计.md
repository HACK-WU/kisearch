模块以 `components/ui/` 为设计系统原子层，每个组件采用单文件 + 同名 `.css` 的 BEM 命名约定（如 `zv-btn--primary`、`zv-dialog__panel`），并通过 `index.ts` barrel 集中导出组件与其 Props 类型，供业务模块短路径引用。状态型组件通过独立 `toast-context.ts` 暴露 `ToastContext` 与 `useToast` hook，由 `ToastProvider` 包裹应用根节点；跨组件通信还使用自定义事件（如 `Dialog` 触发 `zv-dialog-stack-change`）。`ErrorBoundary.tsx` 位于 `components/` 顶层，作为应用级 React 错误边界，捕获同步渲染/提交异常并复用 `EmptyState`+`Button` 呈现友好 500 页面，同时支持 `onError` 回调用于遥测。所有组件均为无副作用的纯函数或受控组件，样式完全来自 CSS 变量（依赖 `styles/tokens.css`），不引入第三方 UI 框架。
