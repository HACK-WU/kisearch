- 每个组件文件与同名 `.css` 文件一一对应，并在组件内通过相对路径导入对应样式。
- 类名遵循 BEM 风格并使用 `zv-` 前缀（如 `zv-btn`、`zv-dialog__panel`、`zv-table-wrapper`），变体通过 `--` 修饰符表达。
- 组件以函数式组件为主，Props 接口在组件文件中定义并通过 barrel `index.ts` 统一 re-export，便于重构时只改一处。
- 可选行为通过布尔/回调 props 控制（如 `loading`、`onRowClick`、`rowTestId`），保持组件最小化且无外部依赖。
- 测试用例与组件同目录放置（`.test.tsx`），并通过 `data-testid` 属性提供稳定的 E2E 选择器。
- 需要全局状态的组件通过独立的 context/hook 文件（如 `toast-context.ts`）解耦，避免组件文件混合导出 React 组件与上下文。
