应用入口 `src/App.tsx` 在根层统一装配跨特性共享能力：i18n（react-i18next）、错误边界、Toast、ApiClientProvider（注入 Tauri/Web 双运行时 API 客户端）、以及配置了全局 onError 的 TanStack Query Client；路由由 `src/router/routes.tsx` 集中声明，将 `/collections`、`/embeddings/:name`、`/rerankers/:name` 等路径映射到 pages 下的具体页面组件，所有页面通过 AppShell 布局渲染。

各功能模块（collections、documents、searches、ai、onboarding、embeddings_pages、rerankers_pages）遵循统一约定：每个 feature 目录内以 `api.ts` 暴露类型安全的 REST 调用、`hooks.ts` 封装 @tanstack/react-query 查询/突变 Hook、`index.ts` 再导出供页面使用；页面组件仅消费 hooks，不直接调用 fetch。共享能力集中在 `src/lib`（API 客户端、QueryClient 工厂、错误映射、文件系统浏览、运行时适配），UI 原子组件集中在 `src/components/ui`，被所有 feature 复用。测试通过 Vitest（单元/集成）与 Playwright（E2E）分层覆盖，MSW 用于 mock API。
