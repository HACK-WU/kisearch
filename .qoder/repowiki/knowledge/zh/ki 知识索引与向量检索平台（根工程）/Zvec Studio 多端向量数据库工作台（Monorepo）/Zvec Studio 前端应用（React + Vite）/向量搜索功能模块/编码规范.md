- 对外 API 通过工厂函数（如 `createSearchesApi`）接收注入的 `ApiClient`，便于在 hooks 中组合并使用 React Context 提供的客户端实例。
- 所有网络请求使用 React Query 的 `useMutation` 而非 query，因为搜索是显式用户动作且明确不需要缓存。
- 本地存储读写均包裹 try/catch 并在异常时静默降级（如 Safari 私有模式、配额超限），保证 UI 仍可工作。
- 集合维度的持久化键采用命名空间前缀 `zvec-studio:search-history:{collection}`，避免不同 collection 之间的数据污染。
- 历史条目通过运行时守卫函数（`isEntry`）校验后再解析，确保从 localStorage 恢复的数据结构安全。
