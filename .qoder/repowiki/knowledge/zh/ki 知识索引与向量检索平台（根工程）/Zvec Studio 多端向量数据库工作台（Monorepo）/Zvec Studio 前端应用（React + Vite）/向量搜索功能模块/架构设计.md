模块按职责拆分为三个文件：`api.ts` 通过 `ApiClient.request` 封装对 `/collections/{name}/searches` 的 POST 调用，暴露 `SearchesApi` 接口与 `createSearchesApi` 工厂；`hooks.ts` 基于 `@tanstack/react-query` 的 `useMutation` 实现 `useSearchDocuments`（无缓存的用户意图型查询），并实现 `useSearchHistory` 以 collection 维度在 `localStorage` 中维护最多 `HISTORY_LIMIT=10` 条最近搜索记录；`index.ts` 作为公共入口统一导出类型与 Hook。依赖方向单向：hooks → api → 共享的 `@/lib/api-client`，不反向引用 UI 组件。
