- 所有 API 类型集中在 `src/schema.ts` 中由工具自动生成，并通过 `src/index.ts` 统一 re-export `paths`、`components`、`operations` 三个命名类型作为对外契约。
- `paths` 接口按 REST 路径键组织，每个路径下以 HTTP 方法（get/post/put/delete/patch）为键映射到对应的 `operations[...]` 类型，未使用的方法置为 `never`。
- `components.schemas` 中使用带字面量 discriminant 字段（如 `type: "bm25"`、`kind: "dense"`）的联合类型表达多态数据结构。
- 包配置 `main` 与 `types` 均指向 `src/index.ts`，且 `tsconfig.json` 设置 `noEmit: true`，使该包仅承担类型声明职责而不产出 JS 产物。
