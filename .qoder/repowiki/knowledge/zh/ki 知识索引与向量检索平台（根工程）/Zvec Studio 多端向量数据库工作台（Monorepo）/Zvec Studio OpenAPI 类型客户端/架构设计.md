本模块是一个纯类型声明包（`private: true`，无运行时代码），由 `openapi-typescript` 在 `pnpm --filter frontend gen:api` 时重新生成。
- `src/schema.ts`：唯一被生成的文件，包含按 URL 路径组织的 `paths` 接口、按资源划分的 `components.schemas`（如 Collection、Document、Embedding、Reranker 等）以及 `operations` 映射，每个 HTTP 方法对应一个操作类型。
- `src/index.ts`：极简的 barrel 文件，仅 re-export `paths`、`components`、`operations` 三个命名类型，作为外部依赖的唯一入口，避免调用方直接引用内部生成的 `schema.ts`。
- `package.json` 将 `main` 与 `types` 都指向 `src/index.ts`，配合 `tsconfig.json`（继承 `../../tsconfig.base.json`，`noEmit: true`）实现零编译输出、仅做类型检查。
- 依赖方向单向：上层前端应用通过 `@zvec-studio/api-client` 消费类型，该包不反向依赖任何业务模块。
