- 入口 `bin/ki.mjs` 通过 `COMMANDS` 映射将 `ki <command>` 分发到对应 `src/*.ts`，使用 `child_process.spawn('npx', ['jiti', scriptPath, ...args])` 以子进程方式动态加载 TypeScript；预解析任意位置的 `--config` 注入 `KI_CONFIG_PATH` 环境变量，并透传 `SIGINT/SIGTERM` 信号给子进程。
- 每个 `src/*.ts` 是一个独立的 CLI 子命令：统一基于 `commander` 注册 name/description/command/option/action，在 action 中调用 `loadConfig()/resolveScope()` 解析 scope、`validateScope()` 校验、`ensureVectorAvailable()` 检测向量服务可用性，再委托给 `./lib/*` 中的纯函数（如 `handleDirectImport`、`vectorSearch`、`backupScopeSnapshot`、`executeSyncRelation`、`executeBulkSyncRelation`），自身仅承担参数解析与 JSON 输出。
- 命令按职责划分：导入类（`scan-kb.ts`）、索引与分组类（`manage-index.ts`、`query-group.ts`、`scope.ts`）、关系与文档类（`sync-relation.ts`、`delete-relation.ts`、`doc.ts`、`tag.ts`）、检索与存储类（`search.ts`、`store.ts`）、运维类（`backup.ts`、`restore.ts`、`export.ts`、`config.ts`、`wiki-backfill.ts`、`get-module-info.ts`）。
- 依赖方向单向：CLI → `./lib/*`（config/scope/vector-client/store/relation-map/scoring/group-resolve 等），不反向引用；`scripts/install-latest.sh` 通过 GitHub API / gh CLI / 页面重定向三种方式获取最新发布包并提供 `--local` 安装模式。
