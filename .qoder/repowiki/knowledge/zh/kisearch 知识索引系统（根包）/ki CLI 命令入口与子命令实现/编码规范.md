- 每个子命令文件独立使用 `commander` 定义 name/description/command/option/action，并在文件末尾通过 `_isMain` 守卫（比较 `process.argv[1]` 与 `import.meta.url`）仅在直接运行时调用 `program.parse()`，以便被 MCP 或其他模块 import 复用逻辑。
- 命令 action 中统一先调用 `loadConfig()` 与 `resolveScope()` 解析 scope，再调用 `ensureVectorAvailable()` 检测向量服务可用性，失败时返回 `{ ok: false, error, degraded: true }` 结构。
- 所有命令输出采用统一的 JSON 格式：成功返回 `{ ok: true, ... }`，错误返回 `{ ok: false, error: string }`，并通过 `console.log(JSON.stringify(result, null, 2))` 打印。
- 需要访问向量引擎的命令在 action 结束时显式调用 `closeEngine()` 释放 worker 与 LOCK，确保进程正常退出。
- scope 参数统一通过 `-s, --scope <scope>` 形式声明，并在默认模式下允许省略（回退 default），strict 模式下强制必填。
- 错误处理统一捕获异常后调用 `toErrorPayload(err)` 或 `failJson(...)` 输出结构化错误信息并以 `process.exit(1)` 退出。
