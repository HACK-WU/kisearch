模块由四个职责正交的纯函数/工具文件组成，彼此通过共享类型与常量耦合：
- `scoring.ts`：评分引擎核心，导出 `calculateScore`（基于使用次数与半衰期的衰减公式）、`recordUse`（5 分钟防刷 + 上限截断）、`partitionByScore`（泛型热/温/冷分区，支持新兴席位保留与上限截断）和 `boundaryDecay`（边界进入时的分数衰减），所有函数均为纯函数、不修改输入。
- `import.ts`：统一导入入口 `handleDirectImport`，按 Phase 2~5 串行执行——预读配置与锁 → 扫描白名单文件 → 清洗+切分 → 批量向量化（`bulkVectorize`/`vectorBulkStore`）→ 构建 Group 树 → 写入 relations-cache/local KB → 记录 source；采用方案 D（文件级 relation + memoryIds 多值），并通过 `acquireImportLock`/信号捕获实现中断可恢复与并发互斥。
- `wiki-sync.ts`：Wiki 写回层，`writeBackToWiki`/`backfillWiki` 根据 `group-index.json` 的 source.dir 或 config 的 wikiSync.sourceDir 解析目标目录，调用 `markdown-gen.generateMarkdown` 生成带 YAML frontmatter 的 .md 文件，并支持自动 backfill 补齐历史数据。
- `markdown-gen.ts`：最小化的 Markdown 生成器，仅负责 frontmatter 拼接与 YAML 安全转义，被 export 与 wiki-sync 复用以保证格式一致。
依赖方向单向：`import.ts` → `scoring.ts`（Relation 类型）、`wiki-sync.ts` → `markdown-gen.ts`；各文件不互相反向引用，便于独立测试与替换。
