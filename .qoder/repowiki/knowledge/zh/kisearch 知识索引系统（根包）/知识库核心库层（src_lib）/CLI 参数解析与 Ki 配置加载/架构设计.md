模块由五个松耦合的 .ts 文件组成，按职责分层：
- `cli-args.ts`：手写 argv 解析器的公共工具，提供 `detectUnknownFlags`（基于 Levenshtein 编辑距离给出参数拼写建议）、`parseIntArg`/`parseFloatArg`（带 min/max 范围回退警告）和统一的 JSON 错误输出契约 `failJson` / `toErrorPayload`，供 backup/restore/export 等命令复用。
- `config-schema.ts`：声明式配置校验层，通过 `ConfigNode` 树（string/number/boolean/object/stringArray/literal + fields/value/nullHandling/deprecated/validate）递归遍历原始配置对象，产出 errors（阻断）与 warns（告警），并内置 httpUrl/portRange/positiveInt 等通用校验器及字段名相近建议。
- `config.ts`：配置加载核心，依赖 schema 层做字段校验；按优先级（显式 --config → $KI_CONFIG_PATH → ~/.ki/config.yaml/.yml/.json）查找配置文件，支持 $HOME/~/ 展开与相对路径解析；合并 embedding/mcp/scopeMode/scopes 等结构，维护进程内 `_cached` 单例缓存并提供 `loadConfig`/`resetConfigCache`；导出 `getScopeDataDir`、`resolveScope`（default/strict 模式护栏）、`removeScopeFromConfigFile`（YAML Document API 保留注释写回）等访问器。
- `constants.ts`：全局常量与延迟初始化的运行时数据根（`getKbBaseDir` 懒取 `loadConfig().dataDir`），定义服务标识 `SERVICE_NAME`、分区默认配置、标签集、`KI_ROOT`、`TEMPLATE_DIR` 等。
- `version-guard.ts`：MCP 长驻进程守护，启动时打印版本 banner，并通过 `fs.watch(package.json)` 监听升级事件，仅向 stderr 告警提示重启。
依赖方向单向：`constants.ts` 依赖 `config.ts`，`version-guard.ts` 依赖 `constants.ts`；`config.ts` 依赖 `config-schema.ts`；`cli-args.ts` 不依赖本模块其他文件，保持独立可被任意命令引入。
