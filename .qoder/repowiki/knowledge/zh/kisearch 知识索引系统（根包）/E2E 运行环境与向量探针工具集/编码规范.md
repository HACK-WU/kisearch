- 探针脚本以独立可执行入口组织（`#!/usr/bin/env node` 或 Python 脚本），通过命令行参数或环境变量切换数据源与输出路径，便于在 CI 中直接调用。
- 性能测量统一采用高精度计时：Node 侧使用 `performance.now()` / `process.hrtime.bigint()`，Python 侧使用 `time.perf_counter`，并在输出中以 ms 为单位打印 create/insert/optimize/query 各阶段耗时。
- 混合检索采用 RRF（Reciprocal Rank Fusion）融合多路结果，既实现用户态 RRF，也同时调用 zvec 原生 `multiQuerySync(rerank:'rrf')` 进行交叉验证。
- 向量维度与 metric 在 Schema 定义处集中声明（如 `dimension: 4096`、`COSINE`、HNSW 索引），embedding 函数与查询向量构造与之严格对应。
- E2E 配置通过 YAML（`ki-config.yaml`）集中管理 dataDir/vectorDir/embedding provider/scopes，并由 `env.sh` 通过 `KI_CFG` 注入进程环境，避免硬编码路径。
