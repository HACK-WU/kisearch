- 对外 API 统一通过 `ZvecEngine` 静态工厂 `create`/`open`/`tryOpen` 构造实例，避免裸 new 构造函数。
- 所有跨进程错误通过 `serializeError` 序列化后随 `WorkerResponse.error` 传递，主线程侧用 `deserializeError` + `ERROR_CONSTRUCTORS` 按 name 重建为具体子类异常。
- 大对象（尤其是 `Float32Array`）在 postMessage 中一律通过 `collectTransferables` 收集 buffer 并以 transfer list 发送，实现零拷贝。
- 写路径将失败项聚合到 `WriteResult.errors[]`，成功项正常写入，保证部分失败不影响同批其他文档。
- 对 zvec 阻塞操作（如 `probe` 的 `ZVecOpen`、`close` 的 drain）统一使用 `Promise.race` + setTimeout 超时保护，防止永久挂起。
- 对外仅从 `index.ts` 显式 re-export 白名单中的类型与异常，其余文件（worker、embedding、internal errors）均标记 `@internal` 不导出。
