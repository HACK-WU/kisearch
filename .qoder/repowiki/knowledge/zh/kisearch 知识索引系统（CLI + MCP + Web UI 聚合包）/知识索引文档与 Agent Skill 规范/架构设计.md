本模块为纯文档与配置资源，不参与运行时逻辑，分为三层：
- `docs/`：以 Markdown 形式记录系统架构（architecture.md）、Group/Relation/KB 文件契约（group-index.json、relations-cache.json、kb/{scope}/{group}/index.json）、CLI 命令指南（cli.md、ki-command-guide.md）、知识库构建/扫描/查询/备份恢复/标签设计/MCP HTTP 接口等全生命周期文档。
- `_template/`：提供 `group-index.json`、`relations-cache.json` 的空结构模板，供初始化或脚本生成时作为基线。
- `skills/`：按 Agent Skill 目录约定组织，每个子目录含 `SKILL.md`（可选 `AGENTS-template.md`），定义 AI 调用 ki MCP 工具的行为决策流程（如 `agents-md-init` 负责 AGENTS.md 初始化/增量刷新，`ki-search` 规定四步走检索策略、写入白名单/黑名单与批量写入约束）。
依赖方向单向向外：Agent 通过 MCP 协议读取这些文档/Skill 来理解并调用 `knowledge-index` 的 CLI/MCP Server；模块本身不依赖任何代码实现。
