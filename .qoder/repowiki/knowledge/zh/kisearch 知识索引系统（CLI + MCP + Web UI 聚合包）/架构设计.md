根目录作为 npm 包入口（package.json 中 bin/ki.mjs），通过 scripts 脚本把各子模块串联为统一产品：cli_commands 提供 19 个 ki 子命令，调用 core_lib（src/lib）中的存储、MCP、搜索、导入导出等共享能力；core_lib 依赖 zvec_engine（编译产物位于 dist/zvec-engine/，由 build:zvec-engine 构建）完成向量检索；web_ui 在 ki mcp --http --web 时作为静态资源与 /api/* 扩展路由挂载到同一 HTTP 单例进程；python_mcp_server 提供独立的 FastMCP 服务，与 Node 侧共享底层 zvec 向量库文件；tests 覆盖 CLI、MCP（HTTP/STDIO）、ZvecEngine、Wiki 导入导出等跨层场景；knowledge_bases_and_data 与 docs_and_assets 分别提供示例知识库与 Agent Skill/Rules 规范，被 CLI 导入与 Agent 消费。所有组件通过 ~/.ki/config.yaml（scope、dataDir、vectorDir、embedding provider）和 scope 隔离机制实现数据与权限边界一致。
