- 入口 `bin/ki.mjs` 通过 `COMMANDS` 映射将 `ki <command>` 分发到对应 `src/*.ts`，使用 `npx jiti` 以子进程方式执行 TypeScript 脚本，并透传 `SIGINT/SIGTERM` 信号；支持 `--daemon` 后台模式（仅 mcp 命令）。
- 每个 `src/*.ts` 是一个独立的 CLI 子命令，统一基于 `commander` 注册命令、选项与 action，并通过 `loadConfig()/resolveScope()` 读取配置、校验 scope，再委托给 `./lib/*` 中的纯函数（如 `handleDirectImport`、`vectorSearch`、`backupScopeSnapshot` 等），自身只承担参数解析与 JSON 输出。
- 命令按职责划分：导入类（`scan-kb.ts`）、索引与分组类（`manage-index.ts`、`query-group.ts`、`scope.ts`）、关系与文档类（`sync-relation.ts`、`delete-relation.ts`、`doc.ts`、`tag.ts`）、检索与存储类（`search.ts`、`store.ts`）、运维类（`backup.ts`、`restore.ts`、`export.ts`、`config.ts`、`wiki-backfill.ts`、`get-module-info.ts`）。
- 依赖方向单向：CLI → `./lib/*`（config/scope/vector-client/store/relation-map/scoring/group-resolve 等），不反向引用；`scripts/install-latest.sh` 提供通过 GitHub Releases 自动安装最新 tgz 的 shell 工具链。
