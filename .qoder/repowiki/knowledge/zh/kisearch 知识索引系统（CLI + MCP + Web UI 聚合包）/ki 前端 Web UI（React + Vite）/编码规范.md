- API 层按领域拆分文件（httpApi.ts 对应 REST、mcpClient.ts 对应 MCP 工具），每个导出函数对应一个后端端点或工具名，并在文件顶部注释说明用途与参数来源。
- 所有网络请求统一通过带泛型的 `req<T>` 或 `callTool<T>` 包装函数发起，返回体直接解包为强类型，错误通过抛出 Error 对象传递。
- 跨页面共享状态（如 scope）通过 React Context + useState 管理，并使用 localStorage 做持久化，读写操作包裹 try/catch 以容忍禁用存储的环境。
- 页面组件按功能职责单一划分（BrowsePage/SearchPage/ImportPage/WritePage/DashboardPage），并通过 `layouts/AppShell.tsx` 提供统一外壳，路由采用 react-router-dom 的嵌套 Route 模式组织。
- MCP 客户端使用模块级单例 `client` 配合 `connecting` Promise 防止并发重复连接，并在捕获错误后调用 `reconnect()` 重建会话后重试一次。
