模块为独立 Vite 工程（package.json），入口 `src/main.tsx` 挂载 React 根组件；`App.tsx` 自上而下装配三层 Provider：`QueryClientProvider`（@tanstack/react-query，默认重试1次且关闭窗口焦点自动刷新）、`ScopeProvider`（全局 scope 状态，持久化到 localStorage key `ki-web:scope`）、`BrowserRouter`（react-router-dom）。路由在 `src/router/routes.tsx` 中以嵌套 `<Route>` 形式定义，所有页面均包裹在 `layouts/AppShell.tsx` 布局内，子路由包括 Dashboard/Browse/Search/Import/Write 五个页面。数据访问分为两条通道：`api/httpApi.ts` 封装 `/api/*` REST 接口（健康检查、文档列表、文件上传、导入任务、标签等），统一由内部 `req<T>` 函数处理 JSON 解析与错误；`api/mcpClient.ts` 使用 `@modelcontextprotocol/sdk` 的 `StreamableHTTPClientTransport` 直连同源的 `/mcp` 端点，暴露 `ki_scope_list`、`ki_search`、`ki_get_module_info`、`ki_store`、`ki_sync_relation` 等工具调用，并实现单例 Client + 会话失效自动重连。公共组件集中在 `components/`（GroupPathSelect、HealthBanner、MarkdownPreview、ModuleDrawer、ScopeSelect），共享逻辑在 `lib/hooks.ts`、`lib/validators.ts`，样式通过 `styles/ki.css` 全局引入。Vite 配置中 `@` 别名指向 `src/`，开发服务器将 `/api`、`/mcp`、`/healthz` 代理到本机 7423 端口（ki mcp --http），构建产物输出至 `dist/` 由后端静态服务。
