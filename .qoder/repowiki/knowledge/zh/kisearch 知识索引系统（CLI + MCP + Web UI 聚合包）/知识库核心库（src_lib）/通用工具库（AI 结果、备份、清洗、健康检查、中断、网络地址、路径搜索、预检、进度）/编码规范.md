- 所有写盘操作采用临时文件 + `fs.renameSync` 的原子写入模式（如中断标记、导入锁），避免部分写入导致状态不一致。
- 对外部命令执行（tar、sh -c hook）均包裹 try-catch，失败时记录 stderr 或降级处理而不阻断主流程。
- 错误通过自定义类（如 `PreflightError`）携带结构化 `code` 字段，便于调用方统一转成 JSON 错误输出。
- 控制台输出统一走 `process.stderr`，保持 stdout 纯净以承载 JSON 结果。
- 可选能力通过布尔规则对象（如 `CleanRules`）+ `DEFAULT_*` 常量合并的方式启用/关闭，CLI 覆盖时解析字符串再合并。
- 文件系统访问前先做前置预检（可写性、磁盘空间、pid 存活、目录存在），失败即早返回或抛出明确错误码。
