本模块由一组相互独立、无内部依赖的单文件工具组成，每个文件聚焦一个横切关注点并通过命名空间化的函数暴露接口：
- 数据契约：`ai-results.ts` 定义 `ScanResultEntry` 与 `deriveGroupPath`，作为导入条目的最小结构。
- 备份：`backup.ts` 通过 `execFileSync('tar', ...)` 将 scope 目录打包为 `<backupDir>/<scope>/snapshots/snapshot.<ts>.tar.gz`，并暴露 `autoBackup`、`listBackups`；失败仅 stderr 警告不阻断调用方。
- 清洗：`clean.ts` 实现基于规则开关的 Markdown 文本清洗管线（BOM/frontmatter/htmlComment/mermaid/codeBlock/codePath），并提供外部 hook 管道 `runCleanHooks`（stdin→stdout、超时 SIGKILL、失败跳过）。
- 健康检查：`health-check.ts` 聚合配置、目录、apiKey、embedding 连通性/密钥/维度三合一验证、zvec collection 存在性，输出 `HealthReport` 供 `ki doctor` 与 MCP 启动预检共用。
- 中断与并发：`interrupt.ts` 在 `kb/{scope}/import-interrupt.json` 写入中断标记（原子 tmp+rename），在 `.import.lock` 中用 pid 存活检测实现跨进程导入锁，支持残留清理。
- 网络地址：`net-addr.ts` 提供 `isLoopbackHost` / `isLoopbackAddr`，用于 MCP HTTP 鉴权区分本地免鉴权与远程需 Bearer Token。
- 路径搜索：`path-search.ts` 封装对 `vector-client.vectorSearch` 的调用，按 `ki-path` / `ki-relation` 标签做 RRF 融合分 top-1 语义匹配，异常静默降级返回 null。
- 预检：`preflight.ts` 提供 `checkWritable`（试写探针）、`checkDiskSpace`（statfs + 10% 余量）、`estimateDirSize`，统一抛出带 code 的 `PreflightError`。
- 进度：`progress.ts` 仅负责 stderr 控制台进度条（TTY 覆写行、非 TTY 逐行），不污染 stdout JSON。
依赖方向单向向外：各工具可复用 `config.js`、`scope.js`、`vector-client.js` 等上层模块，但彼此之间不互相引用，便于单独测试与替换。
