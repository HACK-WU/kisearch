- 每个 MCP 工具以独立文件 + `registerXxxTool(server)` 函数形式注册，统一通过 `server.tool(name, description, zodSchema, handler)` 声明。
- 工具参数 schema 中 `scope` 字段一律设为 `z.string().optional().default('default')`，使缺省调用走 `default` scope 并由上层鉴权拦截。
- 对可能阻塞的底层调用统一用 `withTimeout(promise, ms, label)` 包裹，并按 READ/WRITE/BULK 三类场景复用 `TOOL_TIMEOUT` 预设。
- 鉴权失败与 scope 越权均写入 `process.stderr` 日志并在响应体中脱敏（不下发具体 scope 名），防止被客户端枚举探测。
- HTTP 请求体读取统一限制 16MB 上限并在数据流阶段拒绝超限，避免内存滥用。
- Token 相关写操作采用「临时文件 + fs.rename」原子落盘，配合 0600 权限与损坏检测，保证多进程安全。
