src/lib 作为知识索引器的核心库层，按职责拆分为五个并列子模块：storage_wal（store/wal/group-resolve/scope 提供 scope 目录与 WAL 原子写入）、mcp_server（mcp-http/mcp-stdio-lock/mcp-token/mcp-tools 实现 HTTP/stdio 双传输、RBAC 鉴权与 MCP Tools 注册）、cli_config（config/config-schema/cli-args/version-guard 负责配置加载与参数校验）、search_scoring（scoring/import/wiki-sync/markdown-gen 实现评分、Markdown 导入与 Wiki 写回）、utilities（backup/clean/health-check/interrupt/net-addr/path-search/preflight/progress 提供跨流程工具）。各子模块通过 src/lib/constants.ts 中的 SERVICE_NAME、DEFAULT_PARTITION_CONFIG、KI_ROOT、getKbBaseDir() 等共享常量与延迟初始化的 kb 根目录进行耦合，确保 MCP 服务身份、数据分区策略与运行时路径在调用方与存储方之间保持一致；CLI 启动后先经 cli_config 解析并预检，再驱动 storage_wal 读写数据，由 mcp_server 暴露查询接口，search_scoring 与 utilities 贯穿导入/同步/备份等业务流程。
