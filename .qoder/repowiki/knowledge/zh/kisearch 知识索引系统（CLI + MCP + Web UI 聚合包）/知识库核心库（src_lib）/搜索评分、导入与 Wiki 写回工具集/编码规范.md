- 评分与分区相关函数（`calculateScore`、`recordUse`、`partitionByScore`、`boundaryDecay`）均设计为纯函数，返回新对象而不修改入参 Relation。
- 对外部不可信输入（relation 名、sourcePath）在进入文件系统操作前进行安全检查（如 `isUnsafeRelationName` 拒绝包含 `/\` 或 `..` 的路径）。
- 长耗时阶段统一通过 `logPhaseStart`/`logProgress`/`logPhaseDone`/`logSummary` 输出结构化进度，避免 TTY 下长路径导致的显示乱码。
- 文件落盘前优先创建父目录（`fs.mkdirSync(dir, { recursive: true })`），保证写入路径存在。
- Wiki 写回与 backfill 共用同一目标目录解析逻辑（`resolveWikiTarget`）与安全判定（`isUnsafeRelationName`），避免规则漂移。
- Markdown 输出统一经由 `generateMarkdown` 生成 YAML frontmatter，并使用 `yamlSafe` 对字段值做特殊字符转义，确保 frontmatter 合法。
