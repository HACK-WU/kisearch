- 所有对磁盘的 JSON 写入统一经 walWrite 包装，先写 .tmp 再 atomic rename，禁止直接 fs.writeFileSync 覆盖目标文件。
- scope 参数在进入任何路径构造或 I/O 前必须调用 validateScope，确保仅允许字母、数字、连字符、下划线，非法输入抛出带 code 的 ScopeError。
- JSON 文件读写统一附加 version 与 updatedAt 字段，读侧 readJson 检查版本兼容性，写侧 writeJson 自动注入元信息。
- 数据结构演进通过 migrateGroupIndex / migrateRelationsCacheKeys 等迁移函数就地转换旧格式并写回，调用方始终消费新形态接口。
- Group 路径操作一律以 '/' 分段、filter(Boolean) 去空段后再遍历树节点，避免首尾斜杠导致的空段误判。
- 缓存类模块（relation-map.ts）采用模块级 Map 单例 + mtime/size/TTL 三重失效，并在读取失败时静默降级而非抛错。
