模块按职责划分为四个协作子层：
- 持久化层（wal.ts）：实现跨进程写锁（.lock 文件 + O_EXCL）、临时文件 .tmp → atomic rename 的 WAL 写入流程，并提供陈旧锁/残留 .tmp 清理；通过 Atomics.wait 实现同步阻塞以适配现有同步 API。
- Scope 与数据层（store.ts、scope.ts）：封装 kb/{scope}/ 目录的创建、初始化（从 _template 复制 group-index.json 与 relations-cache.json）、JSON 读写（readJson/writeJson），并集中处理 group-index 旧格式迁移（roots→groups）及 relations-cache key 前缀迁移（"项目根/" 去除）；validateScope 用正则限制 scope 仅含字母数字连字符下划线，防止路径遍历。
- Group 解析层（group-resolve.ts）：在 group-index 树与 relations-cache.groups 上执行四层查找（直接匹配→顶层补全→部分匹配→向量语义兜底 searchPath('ki-path')），返回 ResolveResult 统一提示与候选。
- 反查映射层（relation-map.ts）：模块级单例 Map<scope, CacheEntry> 维护 memoryId→{group,relation} 的反查表，基于 mtime+size+TTL 失效策略懒构建，读取失败时降级为空 Map。
依赖方向单向：store.ts → wal.ts/scope.ts；group-resolve.ts → scope.ts/path-search.ts；relation-map.ts → scope.ts；各层不互相反向引用，边界清晰。
