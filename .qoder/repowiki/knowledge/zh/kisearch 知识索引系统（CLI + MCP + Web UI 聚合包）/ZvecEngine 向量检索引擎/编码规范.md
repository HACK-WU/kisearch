- 对外 API 统一通过 engine.ts 的 ZvecEngine 类暴露，所有子模块（embedding/filter/schema/search）仅作为内部依赖被引用，不在 index.ts 中直接导出。
- 跨进程数据通过 worker-protocol.ts 定义的 Payload 类型序列化传递，主线程负责将 JS 对象转换为 Float32Array 等二进制格式后再下发。
- 错误处理遵循 v5 §4.5 契约：所有业务异常集中在 errors.ts 中以类型化 Error 子类抛出，并在 index.ts 统一 re-export。
- 可插拔能力通过接口抽象（如 EmbeddingProvider、Filter 表达式）实现，具体实现（siliconflow.ts、compiler.ts）在运行时注入而非硬编码。
- 资源清理采用 try/catch 包裹 proxy.terminate()，确保即使 spawn 失败也能回收已分配的 worker 进程。
