- Wiki 页面采用中文文件名并带两位序号前缀（如 `01-概览与架构.md`），便于排序与检索。
- 每篇 Wiki 顶部必须包含 `<cite>` 引用块，并在每个 `##`/`###` 小节末尾附“章节来源”，Mermaid 图后紧跟“图表来源”。
- 所有源码引用统一使用 `file://相对路径#Lx-Ly` 行号区间形式，禁止裸相对路径。
- module-experts 下每个专家目录遵循固定结构：`C0-使用总览.md`、`C1-能力契约.md`、`C2-使用流程.md`、`implementation/` 实现说明、可选 `sub-experts/` 与 `agent.md`。
- knowledge-indexer 产物目录（kb、monitor-memory、user-profile）均以 `group-index.json`、`relations-cache.json` 和子目录 `index.json` 作为组索引与关系缓存。
- wiki_incremental 子命令通过 argparse subparsers 统一入口分发，各子命令参数以 `--xxx` 形式传递并由对应模块的 `main()` 函数处理。
