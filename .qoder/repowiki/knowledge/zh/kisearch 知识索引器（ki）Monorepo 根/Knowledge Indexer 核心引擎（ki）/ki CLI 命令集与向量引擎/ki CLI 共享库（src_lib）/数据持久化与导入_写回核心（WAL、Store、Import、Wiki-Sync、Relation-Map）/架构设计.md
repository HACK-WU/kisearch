模块按职责划分为四个协作子层，依赖方向单向：
- 持久化层（store.ts + wal.ts）：`walWrite` 通过 `.lock` 文件锁 + `.tmp` 临时文件 + `fs.renameSync` 实现跨进程原子写入，提供 `readJson`/`writeJson` 封装 version 检查与 `updatedAt` 注入；`store.ts` 在此基础上提供 `ensureScopeDir`、`initScope`（从 `_template/` 复制模板）、`readGroupIndex`（自动迁移旧 roots→groups 格式及 relations-cache key 前缀）。
- 导入层（import.ts）：`handleDirectImport` 是统一入口，按 Phase 2~5 串行执行——扫描 Markdown → 清洗+切分 → 调用 `batch-vectorize`/`vector-client` 向量化 → 构建 Group 树 → 写 `relations-cache.json` + local KB → 记录 source 块；通过 `acquireImportLock`/信号捕获实现中断可恢复与并发互斥。
- 写回层（wiki-sync.ts）：`writeBackToWiki`/`backfillWiki` 依据 group-index source 或 config 解析目标目录，生成 Markdown 并落盘，支持 autoBackfill 自动补齐历史关系，失败不抛异常仅返回结果对象。
- 反查层（relation-map.ts）：模块级单例 Map 缓存 `memoryId → {group, relation}`，以 relations-cache 的 mtime+size+TTL 失效策略在 search 路径中 O(1) 反查。
所有写操作均经 `walWrite` 保证原子性，读路径通过 `readJson` 做版本兼容与损坏保护。
