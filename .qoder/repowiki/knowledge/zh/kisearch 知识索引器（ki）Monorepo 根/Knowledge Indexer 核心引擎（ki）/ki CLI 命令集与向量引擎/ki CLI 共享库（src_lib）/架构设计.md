src/lib 按职责划分为若干独立子模块，由上层 CLI 命令与 MCP 工具按需组合调用：
- scope_config_cli 提供 Group/scope/group-index.json 的读写与路径补全，被 data_store_wal（store.ts/import.ts/wiki-sync.ts）、vector_indexing（batch-vectorize.ts/path-vectorize.ts/rebuild-vector.ts/scoring.ts）以及 mcp-tools 中的 query-group、scope-list、tag-list 等工具共同消费。
- data_store_wal 通过 store.ts 暴露 ScopeStore 抽象，供 vector_indexing 写入向量元数据、mcp-tools 的 bulk-store/sync-relation 等做持久化，并由 health_version_guards 的 preflight.ts 在写操作前校验磁盘与权限。
- vector_indexing 封装 ZvecEngine，统一被 batch-vectorize、path-vectorize、rebuild-vector、scoring、mcp-tools 的 search 等检索入口调用，对外仅暴露 index/search/rebuild 接口。
- ai_markdown_progress 提供条目结构、frontmatter 生成与进度输出，被 import.ts、markdown_gen.ts、wiki-sync.ts 复用。
- health_version_guards 集中 interrupt.ts、version-guard.ts、preflight.ts、health-check.ts，作为所有写/长驻操作的统一前置守卫。
- mcp-tools 下的 HTTP/stdio 传输层（mcp-http.ts/mcp-http-api.ts/mcp-stdio-lock.ts/mcp-token.ts）将上述能力注册为 MCP 工具，形成 CLI 与 MCP 双入口共享同一业务逻辑的架构。
- 辅助工具 chunker.ts、relation-map.ts、net-addr.ts、path-search.ts、wal.ts、progress.ts、constants.ts、config.ts、cli-args.ts 在各子模块间横向复用，构成统一的底层设施。
