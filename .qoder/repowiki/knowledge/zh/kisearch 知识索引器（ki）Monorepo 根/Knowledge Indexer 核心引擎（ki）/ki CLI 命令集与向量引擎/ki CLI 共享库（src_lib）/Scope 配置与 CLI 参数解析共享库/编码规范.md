- 对外抛出的业务异常统一继承 Error 并携带 code 字段（如 ScopeError 的 EMPTY_SCOPE/INVALID_SCOPE），以便 toErrorPayload 统一序列化输出。
- 所有涉及 scope 的公开函数在入口处调用 validateScope 进行白名单校验（字母、数字、连字符、下划线），拒绝路径遍历字符。
- 对持久化文件（group-index.json）的读写采用「先读后写」模式：readFileSync 解析为 Record<string, unknown>，必要时经 migrateGroupIndex 兼容旧格式后再写回。
- Group 路径解析统一以 '/' 分段并 filter(Boolean) 去除空段，pathExistsInTree/findLongestExistingPrefix/getDirectChildren 共用同一套分段遍历逻辑。
- 向量搜索失败（网络/服务不可用/API 错误）一律 catch 并静默降级返回 null，由调用方决定是否回退到非向量路径。
- CLI 参数解析通过 detectUnknownFlags + valueFlags 集合区分布尔型与带值参数，未知参数使用 Levenshtein 编辑距离给出最接近的正确 flag 建议。
