本模块由五个相互协作的纯函数/类文件组成，构成 CLI 命令层的共享基础设施：
- `scope.ts`：定义 ScopeError 异常与 SCOPE_PATTERN 正则，集中实现 scope 合法性校验、kb/{scope} 目录构造（getKbDir/getGroupIndexPath/getLocalKbDir）、group-index.json 的 source 块读取/写入（getSource/setSource）及旧格式迁移（migrateGroupIndex），并通过 listAllScopes 扫描 dataDir 与 config.scopes 枚举已初始化 scope。
- `constants.ts`：集中声明数据版本、服务名 SERVICE_NAME、分区默认配置 DEFAULT_PARTITION_CONFIG、默认标签集 DEFAULT_TAGS 与 RESERVED_TAGS，并提供 parseContentTags 统一过滤内部保留标签；通过延迟初始化的 getKbBaseDir 暴露 kb/ 根目录与 TEMPLATE_DIR。
- `cli-args.ts`：面向手写 argv 解析器的公共工具，提供 failJson/toErrorPayload 统一 JSON 错误契约、基于 Levenshtein 编辑距离的 detectUnknownFlags 未知参数检测与建议、parseIntArg/parseFloatArg 带边界校验的参数解析。
- `path-search.ts`：封装 vector-client.vectorSearch 调用，按 ki-path / ki-relation 标签进行 RRF 融合分语义搜索，extractPathFromContent 从存储文本中还原路径或关系名，异常时静默降级返回 null。
- `group-resolve.ts`：组合 scope.ts 的 GroupIndex 类型与 path-search.ts 的 searchPath，实现四层查找策略（直接匹配 → group-index 树匹配 → 顶层前缀整段补全 → 部分匹配提示），并以向量近似匹配作为兜底，最终产出 ResolveResult（含 resolvedPath/hint/matched/candidates/fuzzyMatched/fuzzyScore）。
依赖方向单向：group-resolve → path-search + scope；scope/constants 不依赖其他 lib 模块（仅依赖外部 fs/path/config/vector-client），保证可被任意上层命令复用。
