- CLI 参数统一通过 `getFlagValue(args, '--flag')` 解析，支持 `--flag=value` 与 `--flag value` 两种形式，未知 flag 经 `detectUnknownFlags` 拦截并打印帮助。
- 错误输出统一走 `failJson(message, code)` 并以 JSON 格式返回，便于 IDE 客户端解析；用户提示则写入 `process.stderr` 而非 stdout。
- HTTP 鉴权按绑定地址条件生效：回环地址（`isLoopbackHost`）免鉴权，非回环强制校验 `Authorization: Bearer`，并使用 `crypto.timingSafeEqual` 常量时间比较 Token。
- 进程间协调采用文件系统 lock：HTTP 单例写 `~/.ki/mcp-http.lock`，stdio 多实例写 `~/.ki/mcp-stdio-<pid>.lock`，读取时均用 `process.kill(pid, 0)` 探测存活并清理陈旧锁。
- 每个 MCP 会话在 HTTP 模式下新建独立的 `McpServer` + `StreamableHTTPServerTransport`，通过 `mcp-session-id` 头关联，并在 Map 中维护最近活跃时间用于空闲回收。
- 工具层按 `authScopes` 注入权限集合，越权校验集中在 `findScopeViolation` 对 `tools/call` 请求体做批量检查，白名单枚举工具（`SCOPE_LESS_TOOLS`）交由工具层过滤兜底。
