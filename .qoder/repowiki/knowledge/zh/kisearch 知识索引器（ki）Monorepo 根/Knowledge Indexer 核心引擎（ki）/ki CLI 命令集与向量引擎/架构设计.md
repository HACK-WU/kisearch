顶层 src/ 下每个 .ts 文件即一个可执行的 Node CLI（#!/usr/bin/env node + new Command()），按职责划分为：面向用户的检索/文档/标签命令（search/doc/tag）、备份还原导出（backup/restore/export）、关系同步与 Wiki 补齐（sync-relation/delete-relation/wiki-backfill）、运维诊断（doctor/manage-index/query-group/get-module-info）、MCP 服务器（mcp-server）以及配置管理（config）。所有命令不重复实现业务逻辑，而是通过 import 复用 src/lib/* 中的共享库（cli-args、config、scope、store、wal、vector-client、group-resolve、import、markdown-gen、health-check、preflight、progress、interrupt 等），并由 src/zvec-engine 提供独立的向量索引进程（worker.ts/worker-protocol.ts）隔离 embedding、filter 编译与搜索路由。src/lib/mcp-tools 与 mcp-http*.ts 将同一组能力同时暴露为 MCP 工具与 HTTP API，使 CLI 与 MCP 共享同一份领域模型。各命令之间无直接耦合，仅通过 lib 层契约通信。
