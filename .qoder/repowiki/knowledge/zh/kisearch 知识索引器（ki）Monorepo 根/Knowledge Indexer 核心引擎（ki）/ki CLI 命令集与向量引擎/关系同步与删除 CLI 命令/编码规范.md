- CLI 入口统一以 `#!/usr/bin/env node` 开头，并通过 commander 或手动 `process.argv` 解析参数，最终输出 JSON 字符串到 stdout（`console.log(JSON.stringify(result, null, 2))`）。
- 对外暴露的异步函数返回统一的联合类型结果（如 `{ ok: true; ... } | { ok: false; error: string }`），错误一律走 `ok: false` 分支而非抛异常。
- 所有持久化操作（cache、KB index、group-index）都通过 `readJson`/`writeJson` 读写 JSON 文件，并在修改后显式落盘，避免内存状态与磁盘不一致。
- 向量层调用采用「先写新、再清旧」策略：先 `vectorBulkStore` 写入新向量，成功后再 `vectorDelete` 清理旧的 memoryIds，防止写失败导致数据丢失。
- Wiki 写回统一包裹在 try/catch 中且标记 `wikiSynced`/`wikiReason`，失败不阻塞主流程，保证 cache/KB/向量写入不受 wiki 影响。
- 对非法 relation 名称（含 `/`、`\`、`..`）在写入任何数据前即拒绝，避免产生 cache/向量已写但 wiki 无法落盘的半成品状态。
