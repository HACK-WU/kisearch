三个文件均为独立的 Node 可执行脚本（#!/usr/bin/env node），通过 process.argv 自行解析参数并直接调用 lib/* 工具模块，不依赖上层路由：
- backup.ts：读取 config/scope，校验 scope 已初始化（relations-cache.json 存在），调用 lib/backup.backupScopeSnapshot 生成 snapshot.<ts>.tar.gz 到 config.backupDir/<scope>/snapshots，或 --list 列出已有备份。
- restore.ts：最复杂，支持三种模式——无参/--list 列出可用备份；--from-snapshot [--timestamp] [--yes] 从 tar.gz 覆盖还原（先预检磁盘空间与父目录可写性，再创建安全网快照，删除旧目录后 execFileSync('tar', ...) 解压，失败时自动回滚）；--rebuild-vector 单独重建向量并在成功后清除中断标记；最终统一输出 JSON 并通过 finally 调用 closeEngine() 释放 worker/LOCK。
- export.ts：仅读本地数据（group-index.json + relations-cache.json + local KB index.json），按 Group 树递归遍历 hot_relations，调用 lib/markdown-gen.generateMarkdown 写出 .md 文件，支持 --group 子树导出与 --yes 防覆盖保护。
依赖方向单向指向 lib/config.js、lib/scope.js、lib/backup.js、lib/preflight.js、lib/cli-args.js、lib/vector-client.js、lib/rebuild-vector.js、lib/markdown-gen.js，本模块内三文件互不引用。
