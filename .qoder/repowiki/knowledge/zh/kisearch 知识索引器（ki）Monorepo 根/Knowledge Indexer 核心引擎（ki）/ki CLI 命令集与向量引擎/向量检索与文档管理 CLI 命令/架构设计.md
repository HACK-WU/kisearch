三个文件各自独立实现一个 commander 子命令入口（search.ts、doc.ts、tag.ts），每个文件遵循相同的分层结构：顶层通过 `Command` 注册子命令与选项；中间层暴露 `executeXxx(params)` 纯函数（如 executeSearch、executeDocList、executeDocDelete、executeTagList）供 CLI 与 MCP 共享；底层统一依赖 `./lib/vector-client.js` 访问向量引擎、`./lib/config.js` 解析 scope、`./lib/cli-args.js` 做参数校验。

- search.ts 还额外依赖 `./lib/relation-map.js` 与 `./lib/store.js`，在命中结果上反查 relations-cache 以回填 group/relation 并可选拉取 local KB 原文（REQ-09），同时按 TAG_PRIORITY（ki-search > ki-relation > ki-path）对多 tag 搜索结果排序，并对同一文件的 chunk 重复命中做去重。
- doc.ts 提供 list/delete 两个子命令，delete 路径包含破坏性操作的 --yes 确认流程与跨 scope 护栏（docid = sha256(text+scope)）。
- tag.ts 为只读扫描，支持 --scan-limit 限制扫描量并以 truncated 标记近似结果。

所有命令在执行结束后调用 `closeEngine()` 释放 engine 资源，并通过 `_isMain` 守卫确保被 import 时不自动执行。
