本模块由三个并列的 Node.js CLI 入口文件组成，每个文件独立实现一个 `ki` 子命令：
- `doctor.ts`：通过 `loadConfig` + `runHealthCheck` + `renderHealthReport` 对配置文件、目录可写性、apiKey/embedding 连通性、zvec collection、scopes.default 做只读健康检查，失败时以退出码 1 上报。
- `manage-index.ts`：基于 commander 定义 `--action create|delete|list-scopes`，核心逻辑被拆分为可复用的纯函数 `executeManageCreate` / `executeListScopes` / `executeManageDeleteEmpty`（供 MCP 调用），删除分支通过 `cascadeDeleteGroupData` 级联清理 relations-cache、local-kb index.json 及向量记忆；依赖 `lib/store`、`lib/scope`、`lib/group-resolve`、`lib/vector-client`。
- `query-group.ts`：基于 commander 定义 `--scope/--groups/--mode/--depth/--hot-count`，核心逻辑封装为 `executeQueryGroup`（同样暴露给 MCP），内部按 `lib/scoring.partitionByScore` 将 Group/Relation 划分为 hot/warm/cold/emerging，并提供树形渲染、词云式热门列表、full 模式递归展开；支持语义兜底回退到 `vectorSearch`。
三个文件共享相同的“CLI 解析 → 参数校验 → 调用共享纯函数 → JSON/文本输出”结构，并通过 `import.meta.url` 判断是否直接运行以避免被 import 时触发 CLI。
