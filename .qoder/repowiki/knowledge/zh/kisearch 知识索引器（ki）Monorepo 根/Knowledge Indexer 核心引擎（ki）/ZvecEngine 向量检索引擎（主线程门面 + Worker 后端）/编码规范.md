- 对外 API 统一通过 `ZvecEngine` 静态工厂 `create/open/tryOpen` 构造实例，禁止直接 new 构造函数，失败时自动清理已 spawn 的 worker。
- 所有业务异常继承 `ZvecEngineError` 并携带 `code`/`data`，跨线程通过 `serializeError`/`deserializeError` + `ERROR_CONSTRUCTORS` 映射重建，调用方可用 `instanceof` 统一捕获。
- 写入路径将需要 embed 的 doc 与已有 vector 的 doc 分离，按 `EMBED_BATCH_SIZE=64` 小批调用 provider，单批失败仅标记该批为 `EMBEDDING_FAILED`，其余成功项继续写入，保证失败粒度与 HTTP 调用一致。
- Filter 使用结构化 AST（`and/or/not/field op value`）经 `compileFilter` 编译为白名单校验后的类 SQL 字符串，字段名限制在 `buildAllowedFields` 生成的 `ReadonlySet` 内，嵌套深度上限 32 防 DoS。
- 搜索请求经 `routeSearch` 退化矩阵决策：同时含 fts 与 dense 查询走 `multiQuery` 两路 RRF/weighted 融合，缺任一退化为单路 vector/fts，三者皆缺抛 `InvalidSearchError`。
- 跨线程数据传递优先使用 `Float32Array` + `collectTransferables` 收集 `ArrayBuffer` 走 `postMessage(..., transfer)` 零拷贝，避免大向量序列化的内存与性能开销。
