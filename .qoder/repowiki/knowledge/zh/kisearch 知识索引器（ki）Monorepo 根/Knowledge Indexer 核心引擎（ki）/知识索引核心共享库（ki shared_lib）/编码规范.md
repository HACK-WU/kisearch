- 配置加载采用进程内单例缓存（loadConfig 返回 _cached），并通过 resetConfigCache/resetConfigCache 在写回配置后显式失效。
- 所有 JSON 持久化统一经 store.writeJson 写入，自动追加 version 与 updatedAt 字段，并由 wal.ts 的 WAL 机制保证原子性与跨进程互斥。
- 向量操作一律通过 withEngine 包装，统一处理 engine 单例获取、在途计数、空闲释放锁与 worker 不可用自愈重试。
- scope 参数先经 config.resolveScope 按 scopeMode（default/strict）校验，再传入各子模块，确保 strict 模式下未注册 scope 直接失败。
- MCP HTTP 服务对 /healthz 免鉴权、/api/* 与 /mcp 分离路由，非回环绑定强制 Bearer Token 鉴权并使用 timingSafeEqual 比较。
- 对外暴露的错误对象附加 code 字段（如 CORRUPT_JSON、LOCKED、CORRUPTED、PROBE_ERROR），便于上层区分故障类型并给出恢复指引。
