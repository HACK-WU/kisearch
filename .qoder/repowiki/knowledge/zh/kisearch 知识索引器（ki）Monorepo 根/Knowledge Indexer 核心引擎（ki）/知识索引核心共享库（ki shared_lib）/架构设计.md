模块以 src/lib/ 为根，按职责拆分为若干独立文件，形成「配置→存储→向量→网络→工具」的单向依赖链：
- 配置层：config.ts 统一解析 YAML/JSON 配置文件（~/.ki/config.yaml → config.yml → config.json），维护进程内缓存并提供 KiConfig/ScopeConfig/McpConfig/EmbeddingConfig 等类型；constants.ts 集中 CURRENT_DATA_VERSION、SERVICE_NAME、DEFAULT_TAGS、TEMPLATE_DIR 等全局常量。
- 持久化层：store.ts 封装 JSON read/write 并自动注入 version/updatedAt，配合 wal.ts 实现基于 O_EXCL 锁 + .tmp + atomic rename 的 WAL 写入，保证多进程并发写不损坏、可抢占陈旧锁；scope.ts/scope-resolve/group-resolve/relation-map.ts 管理 kb/{scope} 目录结构、group-index.json 与 relations-cache.json 的迁移与路径计算。
- 向量层：vector-client.ts 作为 ZvecEngine 适配器，封装 collection 创建/打开、hybridSearch/upsert/delete/listIds/fetch，内置撞锁重试、空闲释放锁、engine 单例串行化（_engineOpTail）、worker 不可用自愈；batch-vectorize.ts/path-vectorize.ts/batch-vectorize.ts 提供批量向量化入口。
- 网络与 MCP：mcp-http.ts 基于 @modelcontextprotocol/sdk 的 StreamableHTTPServerTransport 构建 HTTP MCP 服务（/mcp 会话 + /healthz 探活 + /api/* 扩展接口），实现 Bearer Token 鉴权（回环免鉴权、非回环强制）、DNS rebinding 保护、会话空闲回收、幂等单例守护（~/.ki/mcp-http.lock）；mcp-token.ts/mcp-stdio-lock.ts/mcp-stop.ts/mcp-http-api.ts 分别管理多 Token 存储、stdio 多实例锁、停止命令与 API 路由；mcp-tools/ 下每个文件对应一个 MCP 工具（search、bulk-store、delete-relation、query-group 等）。
- 辅助能力：import.ts/clean.ts/chunker.ts/scoring.ts/markdown-gen.ts/wiki-sync.ts/backup.ts/rebuild-vector.ts/vector-client.ts/interrupt.ts/version-guard.ts/progress.ts/net-addr.ts/path-search.ts/preflight.ts 分别负责导入、清洗、分块、评分、Markdown 生成、Wiki 同步、备份、向量重建、中断引导、版本检查、进度上报、地址判断、路径搜索、启动前检查等横切功能。
依赖方向严格自顶向下：CLI/MCP 调用 vector-client → store/wal → config/constants；mcp-tools 仅通过 vector-client/store/config 访问数据，不反向依赖网络层。
