根目录通过 `package.json` 的 `bin.ki` 指向 `bin/ki.mjs`，该入口维护命令到 `src/*.ts` 脚本的映射表，使用 jiti 动态执行各子命令；其中 `mcp` 命令同时承担本地 stdio 模式与 HTTP 单例守护进程两种运行形态，供 web_ui 通过 `/api` 与 `/mcp` 路由调用 zvec_mcp_server 暴露的工具与资源。zvec_studio 作为独立 pnpm workspace 通过 Makefile 编排 Python FastAPI + React + Tauri 三端产物，与 ki 共享底层 @zvec/zvec 向量引擎。probes_and_tools 提供 Python/Node 双实现端到端验证脚本，tests_and_fixtures 集中管理单元测试、集成测试、e2e 网络测试及 mock wiki 数据夹具。docs_and_skills 与 data_and_config 分别承载 GitNexus 专家知识库与需求/记忆数据，被 AI Agent 通过 ki 的 MCP 工具读写。根级 `_template/` 提供 group-index 与 relations-cache 模板，scripts/ 提供 release.sh、install-latest.sh 等发布与安装辅助。
