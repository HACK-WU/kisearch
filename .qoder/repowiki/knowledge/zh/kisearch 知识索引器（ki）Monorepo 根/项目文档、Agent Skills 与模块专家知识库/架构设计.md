本模块由四个相互独立的子目录构成，共同作为 GitNexus 的“外部知识层”：
- `docs/`：面向人类用户的 Markdown 文档集合，覆盖架构、CLI、MCP HTTP、向量引擎、记忆系统、标签设计、备份恢复、工作流等主题，以 `.gitkeep` 占位空目录。
- `skills/`：Claude Code / Claude Desktop 可识别的 SKILL.md 技能包，定义 Agent 在特定场景下的行为规则（如 `ki-search` 的四步走检索流程、`agents-md-init` 模板），通过 YAML frontmatter 声明 name/description 供上层 Skill Loader 发现。
- `.claude/skills/gitnexus/`：GitNexus 自身的 MCP 工具使用指南，每个子目录对应一个 skill（guide/exploring/debugging/impact-analysis/refactoring/cli），由 `gitnexus-guide/SKILL.md` 作为入口路由到具体任务。
- `.module-experts/`：由 expert-team 自动维护的“模块级专家”索引，`INDEX.md` 列出存储/MCP/向量引擎/检索客户端/导入/关系管理六大专家及其源码根、契约层、实现层、测试状态；各专家目录存放对应模块的架构、实现、数据流转、模型、接口、测试、运维等结构化知识，配合 `PROJECT.md` 共享全局上下文。
依赖方向单向向外：这些文件仅被 Claude/Claude Code 读取，不引入任何运行时依赖，也不被源码编译。
