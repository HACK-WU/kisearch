本模块由两个 React 组件构成：`CreateRerankerDialog.tsx` 作为受控弹窗，接收 `open`/`onClose` props 并通过 `useCreateReranker` mutation 调用后端；`RerankerDetailPage.tsx` 基于路由参数 `name` 使用 `useReranker` 查询、`useUpdateReranker`/`useDeleteReranker` 进行编辑与删除。两者均依赖 `@/features/ai/hooks` 中的自定义 hooks 完成数据获取与变更，通过 `react-i18next` 的 `useTranslation` 加载 `pages.ai.reranker*` / `pages.aiFunctions.rerankers*` 键值实现国际化，UI 统一复用 `@/components/ui` 的 Button/Input/Select/Dialog 等原子组件，状态反馈通过 `useToast` 推送。类型定义来自 `@/features/ai/api` 的 `RerankerFunctionRecord`，确保前后端结构一致。
