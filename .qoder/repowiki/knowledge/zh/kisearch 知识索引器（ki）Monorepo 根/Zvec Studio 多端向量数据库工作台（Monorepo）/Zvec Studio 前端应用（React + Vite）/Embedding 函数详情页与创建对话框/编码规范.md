- 所有用户操作（创建、更新、删除、试算）均通过 `@/features/ai/hooks` 提供的 mutation hook（如 `useCreateEmbedding`、`useUpdateEmbedding`）发起，并使用 `onSuccess`/`onError` 回调配合 `useToast` 推送提示。
- 表单中的 JSON 配置以字符串形式双向绑定到 textarea，提交前用 `JSON.parse` 校验，解析失败时通过 toast 返回错误提示。
- 国际化文案统一通过 `useTranslation()` 的 `t(...)` 读取，键名遵循 `pages.aiFunctions.embeddings.*` 或 `pages.ai.embedding.*` 命名空间。
- 对后端返回的 `ApiError` 进行区分处理，将 `error.severity`、`error.messageKey`、`error.message` 映射到 toast 的 severity/title/description。
- 需要跨路由实例保持状态的 UI 片段（如试算面板）通过模块级 `Map` 缓存并按路由参数 key 索引，避免 React Router 复用组件导致的状态丢失。
