模块由两个 React 组件组成：`CreateEmbeddingDialog.tsx` 作为受控弹窗，通过 `useCreateEmbedding` mutation 调用后端创建 EmbeddingFunctionRecord；`EmbeddingDetailPage.tsx` 基于路由参数 `name` 使用 `useEmbedding/useUpdateEmbedding/useDeleteEmbedding` hooks 完成加载、更新与删除，并在页面内嵌一个 `TryEmbeddingSection` 子组件，借助 `useEmbed` 进行在线试算。两者均通过 `@/features/ai/hooks` 与 `@/features/ai/api` 访问 AI 能力层，UI 组件来自 `@/components/ui`，错误反馈统一经 `@/components/ui/toast-context` 的 toast 推送。页面还维护了一个模块级 `tryStateCache` Map，按 embedding name 缓存“试算”输入与结果，配合 React Router 的 `key={data.name}` 在切换不同 embedding 时保留上次状态。样式复用 `collections/CollectionDetailPage.css`，并通过 `iconClass/iconLabel` 根据 config.type 动态渲染 OpenAI/Qwen/Local 图标。
