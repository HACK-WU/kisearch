- 每个业务 feature 目录按 `api.ts`（REST 调用）+ `hooks.ts`（React Query hooks）+ `index.ts`（再导出）三段式组织，页面只消费 hooks。
- 所有网络请求与错误处理通过 `@/lib/api-client` 提供的 ApiClient 与 ApiError 进行，页面不直接使用 fetch/XMLHttpRequest。
- 全局 Toast 与 Query 错误通过 `App.tsx` 顶层的 QueryClientProvider.onError 统一上报，feature 层无需重复处理。
- 组件样式采用 CSS Modules 风格（同名 `.css` 文件）并配合 `src/styles/tokens.css` 中的设计令牌，避免内联样式。
- 测试文件与源码同目录放置（`.test.tsx` / `.test.ts`），使用 Vitest + @testing-library/react，API 通过 MSW handlers 模拟。
