- API 方法统一通过 `client.request<T>(url, { method, body, signal })` 调用，URL 使用模板字符串并以 `encodeURIComponent` 编码 collection 与 id。
- 每个写操作 mutation 的 `onSuccess` 回调均调用 `invalidateAfterWrite(queryClient, collection)` 以失效浏览、详情、集合摘要及全局集合缓存。
- 查询 key 采用分层数组形式（如 `['documents', 'browse', collection, ...]`），并提供独立的 `documentsBrowseQueryKey` / `documentDetailQueryKey` 工厂函数以便外部精确失效。
- 所有请求体与响应类型直接 alias 自 `@zvec-studio/api-client` 的 `components['schemas']`，不在本模块重复定义数据结构。
- React 钩子通过 `useApiClient()` 获取客户端并调用 `createDocumentsApi(client)` 构造实例，避免在组件内直接持有全局 client 引用。
