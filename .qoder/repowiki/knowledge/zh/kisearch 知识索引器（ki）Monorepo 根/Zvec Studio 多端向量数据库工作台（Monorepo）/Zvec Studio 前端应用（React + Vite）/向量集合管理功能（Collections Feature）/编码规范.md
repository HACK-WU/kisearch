- API 绑定采用工厂模式：`createCollectionsApi(client)` 返回平铺的方法对象，每个方法对应一个后端 REST 端点，URL 中的 name/field 一律用 `encodeURIComponent` 编码。
- 类型全部从 `@zvec-studio/api-client` 的 `components['schemas'][...]` 重新导出别名，避免在业务代码中直接引用生成的 schema 路径。
- 每个后端操作都对应一个独立的 `useXxx` React Query hook，mutation 的 `onSuccess` 中通过 `invalidateCollection` 或显式 `qc.invalidateQueries` 刷新相关 query key。
- query key 集中定义为顶层常量（`collectionsQueryKey`、`collectionDetailQueryKey`、`recentCollectionsQueryKey`），并以 `as const` 元组形式声明以保证类型安全。
- 页面组件通过 URL search params（`useSearchParams`）驱动 tab 切换，并使用 `visitedTabs` 本地 state 实现惰性渲染（已访问过的 tab 保持挂载）。
- 向量与字段值转换逻辑抽离到纯函数文件（`vector-utils.ts`、`coerce-field-value.ts`），按数据类型（dense/sparse vector、INT32/BOOL/ARRAY_* 等）分支处理并抛出带字段名的可读错误。
