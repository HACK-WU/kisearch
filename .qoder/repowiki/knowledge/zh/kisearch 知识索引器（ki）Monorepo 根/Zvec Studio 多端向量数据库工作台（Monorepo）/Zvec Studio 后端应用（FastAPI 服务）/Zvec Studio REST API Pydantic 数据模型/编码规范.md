- 每个 Pydantic 模型都设置 `model_config = ConfigDict(extra="forbid")`，禁止传入未声明字段。
- 多态配置/参数通过 `Literal[...]` 类型的 `type` 字段配合 `Annotated[Union, Field(discriminator="type")]` 实现判别联合。
- 名称类字段使用正则表达式（`_NAME_RE`、`_COLLECTION_NAME_RE`、`_AI_FN_NAME_RE`）并在 `field_validator` 中校验，同时检查保留名集合。
- 跨字段业务约束（如 FTS 仅支持 STRING、`id/vector/fts` 三选一、`queries` 与遗留 `vector` 互斥）放在 `@model_validator(mode="after")` 中统一断言。
- 请求/响应模型成对出现（如 `DocumentInsertRequest`/`DocumentInsertResponse`、`EmbeddingFunctionRecord`/`EmbeddingFunctionListResponse`），并通过 `__init__.py` 集中 re-export 供路由层引用。
