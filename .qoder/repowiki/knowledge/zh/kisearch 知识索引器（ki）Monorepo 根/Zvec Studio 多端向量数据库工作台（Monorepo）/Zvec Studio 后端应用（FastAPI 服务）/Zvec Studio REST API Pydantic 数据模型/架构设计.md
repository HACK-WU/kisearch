模块按领域划分为四个 Pydantic 子包：`collection.py` 定义集合 DDL（`CollectionSchema`、`FieldSchema`、`VectorSchema` 及索引参数）、集合 CRUD 请求/响应与最近集合维护；`document.py` 提供文档插入、更新、upsert、批量删除、浏览等 DML 载荷；`search.py` 通过 `QueryParamKind` 枚举 + `Annotated[..., Field(discriminator='type')]` 实现 HNSW/IVF/HNSW_RABITQ/VAMANA/DISKANN/FTS 的多态查询参数，并以 `SearchRequest` 统一多路 `VectorQuerySpec` 与遗留单向量形式；`ai.py` 以同样的 discriminated union 模式表达嵌入函数（default_local_dense/sparse、bm25、qwen_dense/sparse、openai_dense）与重排器（default_local、qwen、rrf、weighted）的配置、持久化记录（`ai_functions.json`）以及 `:embed` / `:rerank` 调用载荷。`__init__.py` 集中 re-export 所有模型，使上层路由仅依赖单一入口。所有模型均启用 `ConfigDict(extra="forbid")` 并配合 `field_validator` / `model_validator` 在解析阶段完成命名规范、字段冲突、索引类型约束等业务校验，从而将错误前移到边界。
