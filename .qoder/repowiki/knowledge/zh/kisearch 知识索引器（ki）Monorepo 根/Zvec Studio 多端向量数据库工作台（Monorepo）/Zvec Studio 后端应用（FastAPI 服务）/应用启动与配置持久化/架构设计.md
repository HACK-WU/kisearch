模块由三个协作文件构成：`settings.py` 通过 Pydantic v2 `BaseSettings` 定义以 `ZVEC_STUDIO_` 为前缀的环境变量配置（host/port/log_level/data_dir/api_prefix/cors_origins），并以 `get_settings()` 返回非缓存实例以便测试覆盖环境变量；`main.py` 暴露 `create_app(settings)` 工厂函数作为 uvicorn 与测试共享的入口，在 FastAPI 实例上按顺序挂载 CORS → JsonLinesAccessLogMiddleware → TraceIdMiddleware 中间件，注册 RFC 7807 错误处理器，挂载 collections/documents/fs/searches/ai 等业务路由以及 `/healthz`/`/readyz` 元路由和隐藏于 schema 的 `/__diag__/` 诊断路由，并通过 `app.state.*` 注入 `CollectionRegistry`、`SdkBackend`、`ConfigStore`、`AIFunctionRegistry`、`AIService` 等运行时单例，同时自动播种内置 embedding/reranker 并可选挂载打包的前端 SPA 静态资源；`config_store.py` 提供线程安全的 `ConfigStore`，以 `<data_dir>/config.json` 存储最近打开集合列表，采用 temp-file + `os.replace` 实现原子写入，并通过 `_migrate` 将旧版 `recentPaths` 格式迁移到当前 `recent` 结构。依赖方向单向：`main.py` 消费 `settings.py` 与 `config_store.py`，三者之间无循环依赖。
