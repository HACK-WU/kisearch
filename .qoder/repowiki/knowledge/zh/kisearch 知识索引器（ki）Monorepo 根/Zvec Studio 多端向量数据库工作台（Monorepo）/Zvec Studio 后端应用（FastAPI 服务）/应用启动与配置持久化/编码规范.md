- 配置项统一通过 Pydantic `Field(default=..., description=...)` 声明，并在 `SettingsConfigDict` 中集中设置 `env_prefix="ZVEC_STUDIO_"`、`env_file=".env"`、`extra="ignore"`、`case_sensitive=False`。
- 应用状态通过 `app.state.*` 注入共享单例（settings、registry、backend、config_store、ai_registry、ai_service），供依赖或测试直接访问。
- 中间件按固定顺序注册：CORS 最外层 → JsonLinesAccessLogMiddleware → TraceIdMiddleware，确保日志可读取 ContextVar 中的 traceId。
- 对磁盘写操作采用临时文件 + `os.replace` 的原子替换模式，并在异常分支清理 `.tmp` 残留，避免崩溃导致配置文件损坏。
- 数据模型使用 `model_config = ConfigDict(extra="ignore")` 容忍未知字段，配合 Pydantic 验证实现向后兼容的增量升级。
- 路由通过工厂函数（`_meta_router`、`_diagnostics_router`）创建并 `include_router(prefix=effective.api_prefix)` 挂载，使所有 API 路径受 `api_prefix` 控制。
