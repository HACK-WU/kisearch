- 每个中间件继承 `starlette.middleware.base.BaseHTTPMiddleware` 并重写 `async dispatch(request, call_next)` 以封装请求处理逻辑。
- 跨中间件共享的请求级上下文通过 `contextvars.ContextVar` 暴露 `get_trace_id()` 函数读取，而非直接访问全局变量。
- 错误响应统一由 `_problem_response` 构造器生成，固定字段包括 type/title/status/code/detail/traceId，并按需附加 sdkException 与 extra。
- 访问日志采用扁平 dict 结构并通过自定义 `JsonLinesFormatter` 序列化为单行 JSON，按 HTTP 状态码映射到 info/warning/error 三级日志级别。
- 包入口 `__init__.py` 仅做 re-export，将中间件类与配置函数集中暴露给外部应用装配。
