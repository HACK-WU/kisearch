- 所有 sidecar 行为开关均通过 `ZVEC_*` 环境变量读取，默认值集中在 `SidecarConfig::from_env()`，使打包脚本可在不重新编译 Rust 的情况下注入路径。
- Rust crate 同时输出 staticlib/cdylib/rlib（`Cargo.toml` 中 `crate-type`），以便同一份代码既作为 Tauri 二进制又可供 `cargo test` 引用。
- sidecar 生命周期相关错误统一用 `thiserror` 枚举 `SidecarError` 表达（Spawn/Timeout/InvalidAddress），并在 `spawn` 失败时主动 kill 子进程防止泄漏。
- 跨平台差异通过 `#[cfg(target_os = "...")]` 分支处理（如端口占用清理使用 `lsof`/`netstat`，disabled 模式下无操作子进程选择 `true`/`cmd`）。
- Tauri 暴露给前端的 invoke 接口保持极简，仅定义必要的 `#[derive(Serialize)]` DTO（如 `SidecarStatus`），业务逻辑全部下沉到 Python 后端。
- 发布配置拆分：开发用 `tauri.conf.json`，生产额外目标通过 `tauri.bundle.conf.json` 叠加 `externalBin`，避免 `cargo check` 因缺少冻结二进制而失败。
