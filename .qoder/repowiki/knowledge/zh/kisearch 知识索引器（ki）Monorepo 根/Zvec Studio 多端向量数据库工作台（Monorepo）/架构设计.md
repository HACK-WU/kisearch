本模块以 monorepo 形式将四个子应用按职责切分并通过共享契约耦合：
- 后端（apps/backend）暴露 FastAPI REST API，其 OpenAPI schema 是跨进程契约的唯一来源。
- packages/api-client 基于该 OpenAPI 自动生成 TypeScript 类型，被 apps/frontend 消费，形成“后端 schema → 前端类型”的单向依赖。
- apps/frontend 通过 TanStack Query + 自研 api-client 调用后端；在开发模式由 Makefile dev 同时启动 uvicorn (7860) 与 Vite (5173)，生产构建产物被拷贝进后端 static 目录由后端托管。
- apps/desktop 是 Tauri v2 Rust shell，sidecar.rs 自动拉起后端 sidecar 并承载 React SPA，实现 macOS/Linux/Windows 打包分发。
- 顶层 Makefile 提供 install/dev/build/lint/test/package/release-check 等统一入口，pnpm-workspace.yaml 仅声明 frontend、desktop 与 packages/*，Python 依赖由 uv 在 apps/backend 内独立管理，CI（.github/workflows/ci.yml、release.yml）复用同一套脚本驱动全链路验证。
