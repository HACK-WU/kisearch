### scope
- 定义：ki 的知识库隔离单元，每个 scope 拥有独立的 dataDir、vectorDir、relations-cache.json 及向量集合（如 `kisearch`、`default`）。导入、查询、备份恢复均以 scope 为单位进行，scope 名是自由键，不参与未知字段校验。
- 别名：知识库范围、scope 名

### Group 树
- 定义：基于 relations-cache.json 构建的文档层级目录结构，由 `ki scan-kb import` 的 Phase 3 生成，前端 /browse 页面的左侧导航即 Group 树。import 完成后 relations-cache.json 被原子重写，mtime 变化触发服务端 docListCache 失效。
- 别名：group tree、目录树

### 撞锁
- 定义：导入 CLI 持有 zvec 向量库独占锁期间，MCP 服务发起向量类请求（如 `ki_scope_list`、搜索）触发 `probeWithRetry` 重试 3 次（每次等待约 2s）后失败的行为。此时 scope 下拉应降级为仅 KB 层枚举，不再阻塞。
- 别名：向量库被占用、collection lock

### KB-only 降级
- 定义：撞锁或向量层不可用时，`executeScopeList` 跳过向量引擎调用，仅返回 KB 层（relations-cache.json 中）的 scope 列表，并附带 `vectorAvailable=false` 与 `vectorReason`，使前端 scope 下拉仍可工作。
- 别名：KB 层枚举、快速降级

### 幂等追加导入
- 定义：`ki scan-kb import` 的重构后语义：以 `--group` 替代旧的 `--root-name`/`--mode`，多次运行同一 source 会幂等地追加而非覆盖，支持增量式更新而不丢失历史数据。
- 别名：幂等导入、--group 追加

### 中断防护（InterruptMark）
- 定义：导入流程新增的容错机制（`src/lib/interrupt.ts`），通过 InterruptMark + import 锁防止导入中途被 Ctrl+C 打断导致 KB 状态不一致，并在下次导入时自愈。
- 别名：interrupt mark、导入锁

### ki doctor
- 定义：ki 的配置体检命令，现升级为四层校验：语法格式（YAML/JSON 解析）、字段名（unknown key 报错 + Levenshtein 拼写建议）、类型（端口越界、非正整数维度等）、取值（非法枚举）。废弃字段（如 `scopes.*.sourceDir`）仅告警不阻断。
- 别名：配置体检、doctor

### ki mcp --http --web
- 定义：ki 的 HTTP 服务模式：`--http` 启动 MCP HTTP 网关（`/mcp` 接口），`--web` 同时托管 `web/dist` 静态前端页面于根路径。升级代码后需 `ki mcp restart` 才能生效，因为进程长驻且不热加载新代码。
- 别名：HTTP 服务、MCP 服务
