## 简介
本章节面向首次部署与日常运维，提供 kisearch 的安装、配置、环境变量、健康检查、scope 模式、嵌入模型、数据目录规划以及常见问题排查指南。kisearch 通过 CLI 与 MCP 协议对外暴露知识索引能力，支持结构化索引与向量语义检索的混合查询。

## 环境要求
- Node.js ≥ 18（项目声明 engines.node >= 18.0.0）
- TypeScript 运行时由 jiti 直接执行，无需预编译；但构建 zvec 引擎需 tsc
- 网络可访问 Embedding 提供商 API（默认 SiliconFlow），或替换为任意 OpenAI 兼容端点
- 可选：curl、jq（一键安装脚本依赖 curl，jq 用于更好的 JSON 解析体验）

## 安装方式
### 一键安装（推荐）
使用官方安装脚本自动获取最新版本并全局安装：
```bash
curl -fsSL https://raw.githubusercontent.com/HACK-WU/kisearch/master/scripts/install-latest.sh | bash
```
脚本会：
- 检测 curl/jq 等依赖
- 尝试通过 GitHub API / gh CLI / 页面重定向获取最新 release
- 比较当前已安装版本，避免重复安装
- 使用 npm install -g 安装二进制命令 ki

### 源码安装（开发 & CLI）
```bash
git clone git@github.com:HACK-WU/kisearch.git && cd kisearch
npm install && npm link
# 构建 zvec 引擎（必需，否则 ki mcp 启动时报找不到模块）
npm run build:zvec-engine
```
构建产物会被引入到 dist/zvec-engine，供运行时加载。

## 初始化与配置文件
### 生成配置文件模板
```bash
ki config init [--dir <path>] [--force]
```
- 默认输出到 $HOME/.ki/config.yaml
- --dir 指定目标目录；--force 覆盖已有配置
- 同时创建 dataDir、backupDir、vectorDir 目录（若权限允许）

### 配置文件查找优先级
1. --config <path> 命令行参数
2. 环境变量 KI_CONFIG_PATH 显式指定路径
3. $HOME/.ki/config.yaml → config.yml → config.json
4. 内置默认值（无配置文件时）

配置文件支持 YAML 与 JSON 两种格式，字段结构一致。YAML 优先，JSON 仅兼容读取并在首次发现时提示迁移。

## 环境变量说明
- SILICONFLOW_API_KEY：Embedding 密钥变量名之一。可在配置 embedding.apiKey 中用 ${SILICONFLOW_API_KEY} 引用，系统不会隐式回退到固定变量名，必须显式声明引用。
- KI_DATA_DIR：仅在 `ki config init` 模板生成阶段生效，用于覆盖默认 dataDir；运行时不作为配置来源。
- KI_CONFIG_PATH：显式指定配置文件路径，优先级高于默认位置。

注意：MCP 场景下，客户端需在 env 字段显式传入 SILICONFLOW_API_KEY，因为 MCP 进程不继承 shell 环境。

## 健康检查工具
使用 ki doctor 进行一次性只读诊断，涵盖：
- 配置文件存在性与字段校验
- dataDir / backupDir / vectorDir 目录存在且可写
- apiKey 是否已配置
- Embedding 连通性、密钥有效性、维度匹配（发送最短请求验证）
- zvec collection 是否已创建
- scopes.default 是否配置

启动前预检：ki mcp 启动会自动执行健康检查，失败项（❌）拒绝启动，警告项（⚠️）继续启动。

## scope 模式配置
scopeMode 控制 scope 的注册与访问策略：
- default（默认）：未传 scope 时静默落 default；任意 scope 自动创建，零摩擦
- strict：必须显式传入已注册的 scope，否则报错（fail-loud）。scopes 的 key 即白名单

在配置文件中设置：
```yaml
scopeMode: default
scopes:
  default: {}
  my-project:
    kbDir: /data/special-kb
```

严格模式下，未传或未注册的 scope 将触发错误，防止跨项目串数据。

## 嵌入模型（Embedding）配置
embedding 配置项：
- provider：siliconflow | openai-compatible（实际提供商由 baseURL 决定）
- baseURL：API 端点（http(s) URL）
- model：模型名称
- dimension：向量维度（kisearch 固定 4096，必须与 collection.dimension 一致）
- apiKey：明文 sk-xxx 或 ${VAR_NAME} 引用环境变量；缺省则 fail-loud

安全建议：优先使用环境变量引用，避免明文入库。

## 数据目录规划
- dataDir：KB 源数据目录，存放各 scope 的原始文档。默认 ~/.ki/kb
- backupDir：备份目录，默认 ~/.ki/backup
- vectorDir：zvec 向量库 collection 目录，默认 ~/.ki/vector。⚠️ schema 创建后不可 alter/drop，增加字段需删 vectorDir 重建并重新导入

scope 级 kbDir：若配置了 scopes.<scope>.kbDir，程序自动拼接 kb/{scope} 子目录，避免污染源码目录。未配置时回退到 dataDir/{scope}。

## 常见配置问题排查
- 配置文件解析失败：检查 YAML/JSON 语法，确认路径展开正确（$HOME、~、相对路径）
- 字段校验失败：按错误清单逐项修正（字段名拼错、类型不符、取值非法）
- apiKey 缺失：在 embedding.apiKey 中写明文或 ${VAR_NAME} 引用；MCP 客户端 env 中传入对应变量
- 维度不匹配：确保 embedding.dimension 与 collection.dimension 一致（kisearch 固定 4096）
- 目录不存在或无写权限：检查 dataDir / backupDir / vectorDir 是否存在且可写
- scope 模式错误：strict 模式下必须显式传入已注册 scope；default 模式可自动创建
- MCP 连接失败：确认 URL、端口、Host 头与 ki mcp --status 输出一致；跨机访问需绑定 0.0.0.0 并启用 Token

## 最佳实践建议
- 使用 YAML 配置文件，便于注释与可读性
- apiKey 优先使用环境变量引用，避免明文入库
- 多项目隔离：使用 strict 模式 + scopes 白名单，明确授权范围
- 向量库独立存储：将 vectorDir 放在高性能磁盘，定期备份
- 导入前运行 ki doctor，确保环境就绪
- 增量更新：修改/新增 source 目录文件后，重新执行 import 命令即可幂等追加
- MCP 安全：跨机访问启用 Token，限制 allowedHosts，避免 DNS rebinding

## 附录：完整配置示例
以下是一份完整的 config.yaml 示例，涵盖数据目录、向量库、Embedding、scope 模式、scope 映射、清洗与导入配置、MCP HTTP 传输默认值：

```yaml
dataDir: /data/kb
backupDir: /data/ki-backup
vectorDir: /root/.ki/vector

embedding:
  provider: siliconflow
  baseURL: https://api.siliconflow.cn/v1
  model: Qwen/Qwen3-Embedding-8B
  dimension: 4096
  apiKey: ${SILICONFLOW_API_KEY}

scopeMode: default

scopes:
  monitor:
    kbDir: /data/kb
    wikiSync:
      enabled: true
      sourceDir: /repo/bk-monitor-wiki/wiki
    clean:
      enabled: true
      rules:
        bom: true
        frontmatter: true
        htmlComment: true
        mermaid: true
        codePath: true
        codeBlock: true
        emptyChunk: true
        keepShortSamples: true
      hooks: []
    import:
      extensions: [.md]
      maxFileSize: 1048576
  docs:
    kbDir: /data/kb

mcp:
  http:
    host: 127.0.0.1
    port: 7423
    allowedHosts: [localhost]
```
