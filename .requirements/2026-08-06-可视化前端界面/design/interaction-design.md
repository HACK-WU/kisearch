# 交互设计：可视化前端界面

> 场景类型：Web 系统（浏览器端应用）
> 状态：草案（阶段 1-3 已确认，阶段 4-6 待确认）

## 1. 角色与意图

| 角色 | 核心目标 | 技术熟悉度 | 交互频率 |
|------|----------|-----------|----------|
| 管理员 | 在浏览器中查看文档数据、上传文档、管理知识库，无需命令行 | 中 | 高（日常使用） |
| 开发人员 | 语义搜索 + 定位原文，快速找到知识 | 高 | 中（按需使用） |

> 本机单用户 Web 工具，无登录/权限体系；写操作保留二次确认以防御误操作。

## 2. 交互场景清单

| 场景编号 | 场景名称 | 触发条件 | 目标角色 | 优先级 | 成功标志 |
|----------|----------|----------|----------|--------|----------|
| S-01 | 总览 Dashboard | 打开应用首页 | 管理员 | P0 | 看到 scope 列表 + 各库统计 + 健康状态 |
| S-02 | 知识库浏览 | 点击导航"知识库" | 管理员 | P0 | 展开 Group 树，查看文档列表与原文 |
| S-03 | 语义搜索 | 点击导航"搜索" | 开发人员/管理员 | P0 | 输入查询得到结果，可定位原文 |
| S-04 | 上传文档与导入 | 点击"上传文档" | 管理员 | P0 | 上传 Markdown 后知识可被搜索到 |
| S-05 | 知识写入 | 点击"写入知识" | 管理员/开发人员 | P1 | 表单提交后新知识可被查询 |
| S-06 | 管理操作 | 点击"管理" | 管理员 | P1 | 受控操作（删除/备份/导出/scope）完成 |
| S-07 | 向量可视化跳转 | 点击导航"向量可视化" | 管理员 | P1 | 新标签页打开 zvec-studio 页面 |

**场景关联性**：
- S-01 是应用入口，S-02~S-07 从总览导航进入，均依赖 S-01 的 scope 选择上下文
- S-04 依赖底层导入通道（REQ-F06）与直导链路（REQ-20260806-001）
- S-05 与 S-02 相关（写入后可立即在浏览中看到）
- S-06 中删除类操作与 S-02/S-03 相关（从列表/搜索结果发起）
- S-07 完全独立（跳转外部应用）

## 3. 交互流程

### 3.1 S-01：总览 Dashboard

```mermaid
flowchart TD
    A["打开应用首页"] --> B{"MCP HTTP 服务是否就绪？"}
    B -->|否| C["显示服务未就绪提示 + 启动指引按钮"]
    C --> D["用户点击启动/重试"]
    D --> B
    B -->|是| E["加载 scope 列表（两层状态）"]
    E --> F{"加载成功？"}
    F -->|否| G["显示错误 + 重试"]
    G --> E
    F -->|是| H["显示各 scope 统计卡片（向量数/Group/tag）+ 健康状态"]
    H --> I["用户选择某个 scope"]
    I --> J["进入该 scope 的知识库浏览（S-02）"]
```

| 节点 | 用户感知 | 备注 |
|------|----------|------|
| 服务未就绪 | 醒目提示 + "启动服务"按钮 | 可一键拉起 `ki mcp --http` |
| scope 卡片 | 名称、两层状态（KB/向量）、统计数字 | 空库显示"空"状态 |
| 选择 scope | 进入浏览页并带 scope 上下文 | scope 上下文全局共享 |

### 3.2 S-02：知识库浏览

```mermaid
flowchart TD
    A["进入知识库浏览页（带 scope）"] --> B["加载 Group 树"]
    B --> C{"加载成功？"}
    C -->|否| D["显示错误 + 重试"]
    D --> B
    C -->|是| E["左侧 Group 树（可展开）+ 右侧文档列表"]
    E --> F["用户展开/点击 Group 节点"]
    F --> G["加载该 Group 的 relations 列表"]
    G --> H["用户点击某 relation"]
    H --> I["查看 Markdown 原文（get-module-info）"]
    E --> J["用户切换 tag 过滤"]
    J --> K["过滤后文档列表刷新"]
```

| 节点 | 用户感知 | 备注 |
|------|----------|------|
| Group 树 | 层级可展开，热/温/冷区有标识 | 对应 `query-group --mode full` |
| relation 列表 | 名称 + 热度标识 | 对应 `query-group` 分区 |
| 原文查看 | Markdown 渲染显示 | 对应 `get-module-info` |
| tag 过滤 | 下拉/多选 tag | 对应 `doc list --tags` |

### 3.3 S-03：语义搜索

```mermaid
flowchart TD
    A["进入搜索页（带 scope）"] --> B["输入自然语言查询"]
    B --> C["设置过滤：tags / threshold / limit"]
    C --> D["点击搜索"]
    D --> E{"查询是否成功？"}
    E -->|否| F["显示错误信息 + 原因"]
    F --> B
    E -->|是| G{"结果是否为空？"}
    G -->|是| H["显示空状态：'未找到相关内容' + 调整建议"]
    G -->|否| I["显示结果列表（内容/得分/group/relation/tags）"]
    I --> J["用户点击某条结果"]
    J --> K["查看原文（S-02 原文视图）"]
    I --> L["用户调整 threshold 重新搜索"]
    L --> D
```

| 节点 | 用户感知 | 备注 |
|------|----------|------|
| 搜索输入 | 即时可搜索（回车提交） | 高频场景重效率 |
| 结果列表 | 每条含内容摘要、得分、定位字段 | 得分提示 RRF 语义（非百分比） |
| 空结果 | 提示调整关键词/tags/threshold | 避免用户困惑 |
| 跳原文 | 可追溯命中来源 | 对应 `get-module-info` |

| 节点 | 用户感知 | 备注 |

## 5. 异常与边界处理

| 异常场景 | 触发条件 | 用户感知 | 恢复路径 | 是否阻断主流程 |
|----------|----------|----------|----------|----------------|
| MCP 服务未启动 | `ki mcp --http` 未运行 | 顶部横幅"服务未就绪" | 一键启动 / 手动启动指引 | 是 |
| 后端调用超时 | 大查询/长导入 | 超时提示 + 重试 | 重试 / 调大阈值 | 否（可返回） |
| 上传文件格式错误 | 非 Markdown / 超大文件 | 文件级校验错误 | 移除该文件重选 | 否 |
| 导入中途失败 | 网络/向量服务异常 | 失败清单 + 已入库部分 | 重试 / 跳过失败项 | 否（部分成功） |
| 删除被拒绝 | 删除非空节点/跨 scope docid | 拒绝原因提示 | 逐条删除或走 CLI | 否 |
| 破坏性操作未确认 | 用户未确认 | 预览 + 明确确认框 | 取消或确认 | 是（执行前） |
| zvec-studio 端口占用 | 7860 被占用 | 启动失败原因 | 手动启动 / 换端口 | 否（S-07 独立） |
| MCP 会话过期 | 空闲 30 分钟回收 | 请求失败自动重连 | 前端自动重新 initialize | 否 |

**边界情况**：
| 场景 | 条件 | 预期行为 |
|------|------|----------|
| 空知识库 | 无任何 scope/文档 | 各页面显示引导（创建/导入第一个知识库） |
| 超大 Group 树 | 节点数很多 | 树懒加载/虚拟滚动，避免卡顿 |
| 搜索无结果 | 查询不命中 | 空状态 + 调整建议（tags/threshold/关键词） |
| 多 scope 切换 | 用户在页面间切换 scope | scope 上下文全局生效，页面间一致 |
| 上传与增量并发 | 上传同时有人导入 | 后端串行化（MCP 单进程），前端展示排队状态 |

## 6. 交互约束

| 约束类型 | 涉及操作 | 约束内容 | 用户感知 |
|----------|----------|----------|----------|
| 不可逆操作 | scope 删除/清空、文档/关系删除 | 必须先展示将删内容预览 + 明确确认 | 二次确认弹窗 |
| 前置条件 | 搜索/浏览/上传 | 需先选择 scope（默认 scope 兜底） | scope 选择器默认值 |
| 前置条件 | 导入 | 需 MCP 服务就绪 | 服务未就绪横幅 |
| 确认点 | 破坏性管理操作 | 对齐 CLI `--yes` 语义 | 确认弹窗 + 将删清单 |
| 依赖关系 | 上传→导入 | 上传文件落盘 sourceDir 后再触发导入 | 导入进度展示 |
| 频率限制 | 导入/写入 | 提交中禁用按钮防重复提交 | 按钮 loading |
| 能力限制 | 删除类操作 | MCP 零破坏性约束，前端仅经确认通道执行（CLI 或新增工具） | 受限能力标注"需 CLI" |
